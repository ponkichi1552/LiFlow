# 家事一覧・説明のスクロール・密集日の表示

対象は2026年11月13日の作業ツリー。main上の既存変更を保ち、実機は読み取り・操作・更新せず、iOSシミュレーターだけで確認する。

## 修正

- 家事一覧は検索欄を固定し、カテゴリを太字、家事を字下げした通常の文字で区別する。検索は一致した説明だけを返し、解除すると展開状態を保つ。説明のない家事や権限の制約は保持する。
- 説明の上方向への移動は、スクロールの開始・上端に加え、スクロール量が変わらない上端での指の動きも受け取る。追加した説明の実測高さで位置を補正する。起動時の自動先読みは行わず、上へ戻る操作が実際に始まったときだけ前の説明を追加する。先読み案は実画面で初期位置がずれたため採用しない。
- 月のセルの必要高さへ、日付・4予定・家事件数・行間・内側余白・週の境界線を含める。収集日もある場合は予定の表示枠数へ反映する。全週の高さはそろえる。
- 1日・2日の展開した家事欄は、実測した日付見出しと時間軸の余地を差し引いて上限を決める。家事が多い場合は専用の欄をスクロールする。
