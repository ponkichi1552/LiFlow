# 複数週周期を保てない移動の防止

2週間ごとの日曜・水曜予定を1日前へ全体移動すると、水曜に対応する火曜だけが1週間遅れる反例を再現した。「今後の予定すべて」も同じ変換を使う。利用者が指定した日付の平行移動とは異なる予定を保存していた。

2026-11-15 22:30:55〜22:33:29 UTCに変更案と影響を比較した。曜日ごとの最初の出現までの距離を比較し、現在の繰り返し形式で保持できない全体／今後移動を保存前に拒否する。元の予定と個別変更を残し、既存のエラー表示で「この予定だけ」を案内する。保存形式や共有protocolを増やさず、毎週、7日単位、時刻だけ、安全な複数週移動、問題の曜日が終了日までに現れない短い予定を維持する。

変更は`calendarSeriesMovedDraft`の週ルール変換だけ。最大7曜日の比較であり、実行時に期間全体を展開しない。新規7件を含む関連241件、lint・型検査が成功した。127通りの曜日集合と年境界・有限期間の独立した日付展開比較、両OSの月／2日／3日／7日表示からの拒否と今回だけへの再選択、時刻移動と実SQLiteのUndo、個別変更・削除・Google bodyの保持を検査した。

合成Google API境界では、拒否された移動のローカル保存・Google書き込みは0。今回だけの移動とUndoは同じinstanceへPATCH2回、futureの移動とUndoは元の有効master1件へ戻り、その後の追加書き込みは0だった。実Googleや実機ドラッグの再検査完了とは扱わない。nativeへの反映結果は実施後に追記する。
