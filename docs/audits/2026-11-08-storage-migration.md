# LiFlow 外部ストレージ整理（2026年11月8日）

利用者の容量削減指示により、同じmain作業コピーを保持し、不要な生成物と過去の検査資料を外部へ移した。コピー後の内容照合が完了したものだけ内蔵側の実体を削除した。開発用ソース・Gitの共通ディレクトリ・資格情報・実機とシミュレーターの利用者データは削除していない。

## 照合済みの移行

- 古いシミュレータービルド：元のファイル計8,415,784,419 bytesをtar.gz（3,075,027,521 bytes）へ保存。全ファイルのSHA-256、パス、リンク先を照合。現在必要なReleaseアプリは別途メタデータを保ったまま外部へコピーし、署名も検証した。元のビルドパスはそのアプリへ接続している。
- 生成キャッシュ76ディレクトリ：元のファイル計47,994,132,920 bytes、211,423ファイルを単一アーカイブへ保存。gzip全体の整合性、各ペイロードのSHA-256とパス・シンボリックリンクを照合してから内蔵側を削除。Gradle・npm・CocoaPods・React Native・旧DerivedData・Androidの生成ディレクトリ等が対象。元のキャッシュパスは新しい外部キャッシュへ接続し、今後の再生成も外部に置く。生成キャッシュの拡張属性はアーカイブ対象外。
- 旧APK4本：各内容ハッシュを照合して外部へ移し、元のファイルパスを維持。
- 過去の検査資料等74パス：計2,501,904,540 bytes。ログ、検査用環境、スクリーンショット、LiFlowの監査PDF・検討MD・検査ZIP等をAES-256暗号化APFSイメージ内へコピー。ファイル単位の内容・リンクを照合後に元の実体を削除し、74パスすべての移行先への解決を確認。利用中のFirestore emulator出力と今回の作業ディレクトリは保持。

ファイルサイズの合計はハードリンク等も含む論理量であり、そのまま物理的な空き容量の増加量とはしない。作業開始時の空きは1GB未満。移行後の観測では約36GiBの空きを確認した。OS・シミュレーターの実行中キャッシュにより空きは変動する。

- 一括照合記録：`/Volumes/DockerExternal/LiFlowColdStorage/2026-11-08-0915/MIGRATION-VERIFIED.json`
- ビルドのアーカイブと必要な実行用アプリ：同ディレクトリの`archives/`、`runtime/`。
- 生成キャッシュのアーカイブ：`/Volumes/IoDATAHDD/LiFlowColdStorage/2026-11-08-0915/generated-caches.tar.gz`
- 生成キャッシュの全件マニフェスト：同ディレクトリの`generated-caches-manifest.json`。
