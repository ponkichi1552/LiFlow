# 本人の誕生日表示の試作（2026-11-14）

後続の試作で月表示の日付マーカーをプレゼントボックスへ変更した。現在の仕様・画面と検証は [月表示の文字と誕生日マーカー](2026-11-14-gift-month-preview.md) を参照。本書はケーキ案の確認記録として保持する。

採用文言は「お誕生日おめでとう！」。ホームの日付の下に一言だけ表示し、操作用の青と区別した落ち着いたピンク系の文字と淡い背景を使う。ケーキは丸いホールケーキ・ろうそく1本の共通ベクターへ変更した。

月表示では本人の誕生日の日付の丸をケーキ形へ置き換え、数字を中に残した。横の小さなアイコンと本人誕生日の予定行は表示しない。1日・2日・リストの誕生日表示と編集は維持する。他人の誕生日はホームのお祝い条件に含めない。

表示には既存の個人カレンダーキャッシュを利用する。追加のDB読込・通信・予定作成は行わない。翌日、本人の登録変更・解除、既存の繰り返し例外に従って通常表示へ戻る。2/29の扱いも既存のカレンダーの規則を保つ。共有ホームでは本人のローカル日付が利用できるときはそれを使う。
