# 家事説明の操作を整理

2026年11月13日の指示に合わせ、「この家事の実施履歴を見る」「未完了を記録」を個人の説明と共有画面内の個人説明から削除した。専用の未完了記録部品も削除した。履歴の保存・表示、学習、既存の完了・取消し処理は変更していない。

「予定に追加」は個人・共有で使う共通部品をチェックボックスに変更。管理者以外の変更禁止、周期選択が必要な家事の設定への誘導、処理中の連打防止、保存失敗後の再操作を保つ。

従来の「説明から未完了を記録できる」画面契約は、今回の指示に合わせて「説明を読むだけでは未完了記録を書き込まない」契約へ変更した。ストレージ側の不正な未完了記録を防ぐ検査は保持する。
