# 3モードの周期と実作業時間

周期・時間はLiFlowの初期値であり、利用者が変更できる。実作業時間は概算で、単身者全体の実測標準値やメーカー保証値ではない。「最低限」は衛生・安全を保証する下限ではなく、どのモードでも汚れ・におい・機器のお手入れ表示があれば前倒しする。予定計算には記載済みの目安時間と本人の明示設定を使い、完了日から実作業時間を推測して自動補正しない。未定義の値は開発時に検出し、0分や架空値で補完せず、利用者へ新たな計測・入力を求めない。

**時間は1回分の実作業時間。** 道具の準備、手を動かす作業、後片付けを含む。機械運転・つけ置き・乾燥・冷却などの待機時間は含めず、待機時間の設定・途中状態の管理は今回の実装範囲に含めない。表示は「目安15分」などとし、時間欄の説明に「待ち時間を除く作業時間」と記載する。

対象は原則として1人分、通常の汚れ、普段から手入れしている状態。長期間放置した汚れや大掃除の時間ではない。複数の部屋・機器・窓等がある場合は対象数に応じて変更する。周期は定期清掃の目安であり、こぼした汚れ・ごみ・異常を次の予定まで放置する指示ではない。 モードは原則として周期だけを変え、作業範囲・初期有効項目・目安時間を自動では変えない。間隔を空けると汚れや量が増えるため、同じ時間で必ず終わるという意味ではない。

## モードの適用ルール

- **こまめ**：汚れがたまる前に手入れしたい人向け。メーカー等の推奨を参考に、短めの周期。

- **標準**：実態調査と手入れの必要性を両方見て、無理なく続けやすい周期。

- **最低限**：標準より間隔を空け、まとめて行いたい人向け。ただし汚れ・におい・機器の表示があれば前倒し。

- 同じ周期が並ぶ項目もある。使用後の残菜処理、水の入れ替え、製氷タンク、機器の指定保守、安全点検などは、モード差を作るためだけに延ばさない。

- 「使用中」は手入れを行う対象の条件であり、アプリが使用季節を判定する指定ではない。取得していない使用状態を推測して周期を開始・停止せず、管理対象は既存の有効・無効設定に従う。使用再開・収納時には状態と説明書を確認する。「必要時」は日数の定期通知を作らず、関連する家事の説明に含める。

- 衣類洗濯の周期は洗濯をまとめる間隔であり、同じ下着や濡れたタオルの連続使用日数ではない。週1回を選ぶ場合は洗い替え・機械容量を確保し、濡れ物や汗・汚れの強い物は早めに洗う。

- 分割表は希望者向け。作業範囲・周期・時間・負荷が明記された項目を使い、元の家事と対象を重複させない。分割しない場合は一式の周期を使う。定義されていない残作業の時間を引き算で作ったり、任意分割・部分完了の新機能を追加したりしない。

# 負荷の基準

負荷は、1回の作業で体にかかる負担を「軽い・普通・重い」の3段階で扱う。実作業時間とは別の情報とし、同じ10分でも、操作中心か、中腰でこする作業か、大きな物を運ぶ作業かで分ける。

| 負荷 | 判断の目安 |
| - | - |
| 軽い | 小さく軽い物を扱う、軽く拭く、操作するなど、強い力や姿勢の負担が少ない作業 |
| 普通 | かがむ、腕を上げる、複数の物を扱う、通常のこすり洗いや持ち運びがある作業 |
| 重い | 大きな物・水を含んだ物を扱う、持ち運びや取り外しに力が必要、負担のある姿勢を繰り返す作業 |

- 各項目の負荷は、一人暮らしの通常量・通常の汚れを想定した編集上の初期値。本人が変更できる。

- 洗濯機の運転、つけ置き、自然乾燥など、手を離せる待ち時間は負荷にも実作業時間にも加えない。ただし、手順上必要な待ち・乾燥確認は省略しない。

- 量・重さ・汚れ・設備の位置が違えば負荷も変わる。無理な持ち上げや足場が必要な作業を、負荷が重いという表示だけで実行させない。

- 危険度や作業方法の難しさは注意事項で説明し、負荷の段階と混同しない。

- モードを変えても負荷を自動で増減させない。本人が必要に応じて既存の個別設定を変更できるが、汚れ・量・実作業時間の追加入力や計測を要求しない。

- 予定作成は当面、既存の実作業時間を使用する。「重い＝時間を何倍」という係数は今回設定しない。

- 登録済みの親子関係と作業範囲に基づき、親へ統合した工程を別負荷として重ねて加算しない。別管理した家事の同時実施を推測した時間・負荷の自動調整は行わない。

# 家事ごとの必要な道具と手順と注意事項

各説明は通常のお手入れ向け。所持・使用している対象だけを扱い、素材の表示と機器・洗剤の説明に合う方法を選ぶ。番号順に作業し、道具は必要なものだけを準備する。

- 道具の「または」は代替手段であり、両方を購入する必要はない。「必要な場合」「機種指定」は該当する時だけ使う。

- 洗剤は一度に1種類だけを使う。別の洗剤が残っている場所へ重ねて使わない。特に塩素系と酸性の洗剤・クエン酸・酢などを接触させない。

- 電気製品は機器ごとの停止・電源・冷却手順に従う。本体内部や電装部へ水や洗剤をかけない。水洗いできる取り外し部品だけを洗い、必要な乾燥を終えてから戻す。

- 分解修理、高所から身を乗り出す作業、不安定な足場の作業は含まない。自分で安全に扱えない対象は管理者や専門業者へ相談する。

- ごみ箱の汚れ対応、カビ取り、使用後フィルターなどの説明を収録しても、初期状態で独立した予定や通知を増やす意味ではない。

- 「参考」は作成・保守時に確認する公式情報。出典の記載を、原文や画像の転載許可として扱わない。

## 基本の家事

### 部屋の清掃

**負荷の目安：普通**　実作業の目安：20分

室内を移動し、床や低い場所も掃除する。

**必要な道具**

- ほこり取り用のモップ

- 掃除機

- 柔らかい布

- ごみ袋

**手順**

1. 床にある小物を片付け、ごみを拾う。重い家具は動かさない。

2. 棚や家具の上を、高い所から低い所へモップで静かになで、ほこりを取る。

3. 床のごみを掃除機で吸う。部屋の奥から出入口へ進み、すみもゆっくり掃除する。

4. 汚れの残る場所だけ、材質に合う方法で拭く。水拭きできる床は固く絞った布を使い、水気を残さない。掃除機のごみは機種指定の方法とタイミングで処理し、道具を片付ける。

**注意事項**

- 椅子に乗ったり背伸びしたりせず、安定して届く範囲だけ掃除する。

- 電源タップや家電の隙間に水を入れない。床用の道具を家具の表面に使い回す前に、汚れや傷のつきやすさを確認する。

**豆知識・手入れのコツ**

### 浴室の清掃

**負荷の目安：重い**　実作業の目安：20分

かがむ姿勢と、浴槽・床をこする動作が続く。

**必要な道具**

- 浴室用中性洗剤

- 柔らかいスポンジ

- 柄付きの浴室ブラシ

- ゴム手袋

- 水気を拭く布

**手順**

1. 換気を始め、小物をよける。排水口のごみ受けから髪の毛を取り、ごみとして捨てる。

2. 浴槽をぬらし、洗剤の表示に従って洗う。ふちや内側をスポンジで軽くこする。

3. 手の届く壁の汚れた部分、鏡・蛇口、床を順に洗う。ごみ受けは最後に洗う。

4. 洗剤を十分に流し、ごみ受けを戻す。鏡・蛇口・浴槽のふちの水気を拭き、換気を続ける。

5. カビがある場合だけ「浴室のカビ取り」を追加する。通常の清掃ごとに行う必要はない。

**注意事項**

- ぬれた床で滑らないようにし、浴槽のふちに乗らない。

- 硬いたわしや研磨剤を自己判断で使わない。コーティングがある鏡は専用の手入れ方法を確認する。

- 別の洗剤を重ねない。カビ取りを続ける場合も、先の洗剤を十分に洗い流し、薬剤の表示に従う。

**豆知識・手入れのコツ**

- **ピンクぬめりは、色が染みつく前に**：浴室のピンクぬめりは、皮脂などを栄養に増えた酵母による汚れの場合があります。放置すると色素が残ることがあるため、見つけたらまず浴室用中性洗剤で洗い、黒カビと同じものと決めつけて強い薬剤を使わないのがコツです。 [LIXIL：浴室の汚れの種類とお手入れ方法](https://www.lixil.co.jp/support/clean/bathroom_tips02.htm)

### トイレの清掃

**負荷の目安：普通**　実作業の目安：10分

便器の内側や床を掃除するため、かがむ。

- 便座用の柔らかい布

- 床用の布

- ゴム手袋

**手順**

1. 換気をし、床の物をよける。温水洗浄便座は説明書に従って電源を切るかプラグを抜く。

2. 固く絞った柔らかい布で、ふた、便座の表裏、便器の外側の順に拭く。汚れた面は折り返して使う。

3. 便器内は中性洗剤の表示に従い、ブラシで内側とふち裏をこすって流す。電源が必要な洗浄操作は説明書で確認する。

4. 床用の布で、便器の足元と周囲を拭く。道具を片付け、乾燥を確認して電源を戻し、手を洗う。

**豆知識・手入れのコツ**

- **便器の足元の水滴は、床のためにも早めに**：便器の周囲にできる黒いシミは、尿だけでなく結露の水分が原因になることもあります。木質の床では放置が腐食につながるため、掃除のついでに便器の根元の濡れも確認すると安心です。 [TOTO：床・壁・天井（トイレ）のお手入れ](https://jp.toto.com/support/maintenance/toilet/cleaningtool/floorwallceiling/)

### 洗面台の清掃

**負荷の目安：軽い**　実作業の目安：5分

狭い範囲を短く洗い、拭き上げる。

**必要な道具**

- 洗面ボウルに使える中性洗剤

- 柔らかいスポンジ

- 柔らかい布

- ゴム手袋

**手順**

1. 洗面台の小物をよけ、ごみ受けの髪の毛などを取って捨てる。

2. ボウルをぬらし、洗剤の表示に従ってスポンジで軽く洗う。ごみ受けも洗い、十分にすすいで戻す。

3. 蛇口と周囲の水はねを固く絞った布で拭く。鏡は加工の有無を確認し、指定の方法で拭く。

4. ボウルと蛇口の水滴を拭き、小物を戻す。布とスポンジをすすいで乾かす。

**注意事項**

- コンセントや照明、収納の継ぎ目に水をかけない。

- 排水口の奥に髪の毛を押し込まない。落ちない汚れに別の洗剤を重ねない。

**豆知識・手入れのコツ**

- **ボウル上部の小さな穴も、汚れの見落とし場所**：洗面ボウル上部の小さな穴は、水があふれるのを防ぐオーバーフロー穴です。穴がある機種では入口の汚れも確認し、取扱説明書で認められる範囲を柔らかいブラシなどで洗うと、ボウルだけ洗う時の見落としを減らせます。 [ノーリツ：洗面化粧台の掃除・お手入れ方法](https://www.noritz.co.jp/aftersupport/maintenance/sanitary.html)

- **化粧品の飛び散りは、水あかとは別物**：洗顔料や化粧品の中には、カウンターの材質を傷めるものがあります。特にヘアカラーやヘアマニキュアは変色・変質の原因になるため、付いたまま次の掃除日まで待たず、設備の説明書に沿ってすぐ取り除きましょう。 [ノーリツ：洗面化粧台の掃除・お手入れ方法](https://www.noritz.co.jp/aftersupport/maintenance/sanitary.html)

参考：[LIXIL：洗面器の日常清掃](https://www.lixil.co.jp/support/clean/powderroom_04_daily.htm)、[LIXIL：洗面化粧室のお手入れ](https://www.lixil.co.jp/support/clean/powderroom.htm)

### シンクの清掃

**負荷の目安：軽い**　実作業の目安：5分

立ったまま小さな範囲を洗う。

**必要な道具**

- 台所用中性洗剤

- シンク用の柔らかいスポンジ

- 排水口用の柔らかいブラシ

- 水気を拭く布

- ゴム手袋

**手順**

1. 食器を片付け、ごみかごの生ごみを取り出して捨てる。

2. スポンジに適量の中性洗剤を付け、シンクの内側とふちを軽く洗う。

3. ごみかごと排水口の見える部分を、別のブラシで洗う。配管は分解しない。

4. 洗剤が残らないようにすすぎ、ごみかごを戻す。シンクと蛇口の水気を拭き、道具を洗って乾かす。

**注意事項**

- 金属たわしや研磨剤は使わず、シンクの材質・コーティングに合う道具を選ぶ。

- 熱湯や油を排水口へ流さない。生ごみを押し込まず回収する。

- ヌメリ取り剤などが置かれている場合、別の洗剤を加える前に使用上の注意を確認する。

**豆知識・手入れのコツ**

- **ステンレスにも「もらいさび」は付く**：濡れた缶や瓶の金属ふたをシンクに置きっぱなしにすると、そこから出たさびが移ることがあります。洗い終わった空き缶やふたをシンクから出しておくと、輪状のさび汚れを予防できます。 [LIXIL：キッチンの汚れの種類とお手入れ方法（水まわり）](https://www.lixil.co.jp/support/clean/kitchen_tips02.htm)

- **シンク周囲の柔らかい目地は、ブラシで磨かない**：シンクまわりの柔らかいコーキングは、歯ブラシやたわしでこすると傷が付き、その傷からカビが生えやすくなります。金属面と同じ力で磨かず、その部分に適合する方法で手入れしましょう。 [LIXIL：キッチンの汚れの種類とお手入れ方法（水まわり）](https://www.lixil.co.jp/support/clean/kitchen_tips02.htm)

参考：[LIXIL：シンクの日常清掃](https://www.lixil.co.jp/support/clean/kitchen_02_daily.htm)、[大和ハウス：キッチンの手入れ](https://www.daiwahouse.co.jp/jutaku/tebiki/room/kitchen.html)

### 玄関の清掃

**負荷の目安：軽い**　実作業の目安：10分

小さな玄関床の掃き取りと部分的な拭き取り。

**必要な道具**

- ほうき

- ちりとり

- 床用の布

- ごみ袋

**手順**

1. 玄関に出ている靴や小物をよけ、床を掃除できるようにする。

2. 奥やすみにたまった砂・ほこりをほうきで集め、ちりとりで取り除く。外や共用廊下へ掃き出さない。

### 衣類・タオルの洗濯

**負荷の目安：普通**　実作業の目安：15分

洗濯物の運搬と、かがむ・腕を上げる動作がある。

**必要な道具**

- 洗濯機（対象の素材・量に対応するもの）

- 洗濯用洗剤

- 洗濯ネット（表示で指定されるもの）

- 洗濯かご

- ハンガー

- 物干し

- 洗濯ばさみ

**手順**

1. 衣類とタオルの洗濯表示を見て、色落ちしやすいもの・手洗い専用のものを分ける。ポケットの中身を出す。

2. ファスナーを閉じ、表示で指定されたものはネットに入れる。目立つ汚れは、使う洗剤の方法に従って先に処置する。

3. 洗濯機の対応する量・素材を確かめ、詰め込まずに入れる。洗剤を計量し、表示に合うコースで洗う。自動投入を使う場合は設定量を確認し、手動で重ねて入れない。

4. 運転終了後は取り出し、形を整えて間隔をあけて干す。乾燥機を使う場合は衣類と機械の両方が対応する条件で乾かす。

5. 袖口やタオルの重なりまで乾いたことを確かめ、たたむかハンガーに掛けて収納する。

6. 洗濯機が止まっていることを確認し、使用後清掃が指定された糸くずフィルターを手入れして戻す。乾燥した回は該当する乾燥フィルターも清掃する。

**注意事項**

- 洗濯可でも乾燥機にかけられるとは限らない。水温・漂白・乾燥の表示も確認する。

- 回転中の槽に手を入れない。防水性の衣類や機械が禁止する品物は、脱水だけでも入れない。

- 食用油や美容オイル等が付いた衣類・タオルは、洗濯後でも乾燥機で加熱しない。

- 排水フィルターは槽内の糸くずフィルターと別物。残水が出るため、この手順で無造作に開けない。

**豆知識・手入れのコツ**

- **ネットは「大きめ」より衣類に合うサイズ**：洗濯ネットを使う衣類は、たたんだ大きさに合う物を選び、基本は1枚ずつ入れる。大きすぎると中で動いてシワが付きやすく、小さすぎると汚れが落ちにくくなる。 [花王：洗濯ネットと干し方でシワ・型崩れを防ぐ](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/107/)

- **角ハンガーは長い物を外側へ**：角ハンガーでは、長い物を両端、短い物を中央に並べる「アーチ干し」を試してみましょう。下に空間ができ、乾きにくい厚手の物も外側にすると風に当たりやすくなります。 [ライオン：角ハンガーを使ったアーチ干し](https://www.lidea.today/articles/175)

- **飲み物のシミと油汚れでは最初の一手が違う**：水洗いできる衣類のコーヒー・しょうゆなどは、水を含ませた布でこすらず押さえて移し取る。カレーやドレッシングなど油を含む汚れは、まず乾いた布やティッシュで油分を吸い取り、帰宅後に表示に合う方法で洗う。水で色落ち・輪ジミになる素材は自己処理しない。 [花王 シミの応急処置](https://www.kao.com/jp/qa/detail/28818/)、[花王 汚れ別の処置](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/012/)

参考：[花王：洗濯表示の意味](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/007/)、[Panasonic：洗濯機・洗濯乾燥機の安全な使い方](https://jpn.faq.panasonic.com/app/answers/detail/p/17912/a_id/61998)、[Panasonic：洗濯機のお手入れ](https://panasonic.jp/wash/contents/care.html)、[日立：タテ型洗濯機の糸くずフィルターのお手入れ](https://kadenfan.hitachi.co.jp/support/wash/q_a/a72.html)、[Panasonic：油分が付いた布類の乾燥機使用に関する注意](https://www.panasonic.com/jp/about/product_information/c/d001.html)

### 寝具カバーの交換・洗濯

**負荷の目安：普通**　実作業の目安：20分

大きな布の着脱と、腕を広げて干す動作がある。

**必要な道具**

- 洗濯機（対象の素材・量に対応するもの）

- 交換用の寝具カバー（必要な場合）

- 洗濯用洗剤

- 洗濯ネット（指定がある場合）

- 洗濯かご

- 物干し

- 洗濯ばさみ

**手順**

1. シーツ・枕カバー・掛け布団カバーを外す。ひもや留め具を先に外し、布団本体を無理に引っ張らない。

2. カバー内側の四隅にたまったごみを取り、洗濯表示を確認する。ファスナーを閉じ、指定があればネットに入れる。

3. 洗濯機の容量と対応コースを確認し、詰め込まずに洗う。一式で多い場合は分ける。

4. 洗い終えたら広げて形を整え、布同士の間に風が通るように干す。乾燥機は表示と機械の条件が合う場合だけ使う。

5. 完全に乾いたカバーを付け直し、掛け布団の角を合わせてひもや留め具を戻す。予備分はたたんで収納する。

**注意事項**

- 大きな布をベランダの手すりに掛けたり、身を乗り出して干したりしない。敷地内の安定した物干しを使う。

- 衣類と同じ洗濯回で処理した場合、共通の投入・フィルター清掃などは重ねて実施しない。

### ごみ・資源の収集日に合わせたごみ出し

**負荷の目安：軽い**　実作業の目安：5分

通常量の袋をまとめ、近くの集積所へ運ぶ。

**必要な道具**

- 地域の指定に合うごみ袋

- 交換用のごみ袋

- 汚れを拭く布

**手順**

1. 自治体の案内で、今日出せる種類・時間・集積所を確認する。祝日や年末年始の変更にも注意する。

2. 対象のごみを集め、分別を確かめる。生ごみは水気を切り、袋の口をしっかり閉じる。

3. ごみ箱に汚れがあれば拭き、乾いてから新しい袋をセットする。広く汚れている場合は「ごみ箱の清掃」の手順を使う。

4. 指定の場所へ持っていき、必要なら防鳥ネットをかけ直す。帰宅後に手を洗う。

**注意事項**

- 電池・スプレー缶・刃物は普通ごみに混ぜず、所在地の最新ルールで出し方を確認する。

- 袋を手で強く押しつぶさない。割れ物や刃物の包み方・表示も自治体に従う。

- 重い袋は無理に一度で運ばず、袋や運搬回数を分ける。

**豆知識・手入れのコツ**

- **乾いた生ごみは、わざわざぬらさない**：玉ねぎの乾いた皮などは、シンクのごみ受けに入れず、乾いたまま分けて捨てると水切りの手間を減らせます。水がかかる場所に置くと余分な水分を吸い、ごみが重くなったり、においの原因になったりするためです。 [川越市：生ごみの水切りをしましょう](https://www.city.kawagoe.saitama.jp/kurashi/gomi/1002421/1002432.html)

参考：[横浜市：ごみと資源物の分け方・出し方（地域差を確認する例）](https://www.city.yokohama.lg.jp/lang/residents/living-guide/garbage/garbage-bunbetsu.html)

腕を上げる動作とかがむ動作を繰り返す。

- 窓の材質に使える中性洗剤

- 床を保護するタオル

**手順**

1. 窓の下にタオルを敷く。外側を無理なく掃除できる足場があるか確かめる。

2. 網戸は外さず、ブラシや布でほこりを取り、固く絞った布で軽く拭く。網を強く押さない。

3. 窓ガラスを水拭きする。残る汚れだけ適合する中性洗剤を表示どおりに使い、水拭きしてから乾いた布で仕上げる。

4. サッシの砂をブラシで集めて取り除き、レールと枠を水拭きする。水気を拭き、開閉・施錠を確かめて片付ける。

**注意事項**

- 窓から身を乗り出したり、椅子や手すりに乗ったりしない。届かない外面は無理に掃除しない。

- ガラスのひびや網戸のぐらつきを見つけたら、作業を止めて管理会社やメーカーへ相談する。

- フィルム・特殊加工があるガラスには、対応が確認できない洗剤や研磨剤を使わない。

**豆知識・手入れのコツ**

- **強い日差しを避けると、拭き跡が残りにくい**：窓まわりを水拭きするなら、日差しの弱い曇りの日や朝夕が向いています。強い日差しでは水分がすぐ乾いて跡が残りやすいため、暑い時間帯を外すだけでも仕上げやすくなります。 [YKK AP：なるほど！掃除の豆知識](https://www.ykkap.co.jp/consumer/satellite/articles/products/amido_textbook/knowledge02.php)

### 冷蔵庫内の清掃

**負荷の目安：普通**　実作業の目安：20分

食品や棚の出し入れと、低い場所の拭き取り。

**必要な道具**

- 保冷容器

- 食品用の保冷剤

- 台所用中性洗剤

- 柔らかい布

- 柔らかいスポンジ

**手順**

1. 道具と保冷剤入りの容器を準備し、食品を移す。説明書を確認し、乾いた手で電源プラグを抜く。

2. 外して洗える棚・ケースだけを取り外す。取り付け位置が分かるように並べる。

3. 庫内を固く絞った布で拭く。残る汚れには薄めた中性洗剤を使い、清潔な布で水拭きする。棚・ケースは指定の方法で洗う。

4. 水気を拭いて棚を戻す。説明書の再通電までの待ち時間を守り、運転を再開する。冷えを確認して食品を戻す。

**注意事項**

- 食品を室温に放置しない。作業中も保冷し、長引く場合は別の冷蔵設備を使う。

**豆知識・手入れのコツ**

- **買い足す前の、食品が少ない日が狙い目**：冷蔵庫をまとめて掃除するなら、食品を使い切って中身が少なくなったタイミングに合わせると、取り出す量も一時保冷する量も減らせます。買い物後より買い足す前に予定すると、棚やケースを外しやすくなります。 [Panasonic：冷蔵庫の掃除](https://panasonic.jp/life/housework/100098.html)

- **レールの油は、汚れとは限らない**：引き出しレールやドアの回転支点に付いている油は、動きを滑らかにする潤滑油の場合があります。そこまで脱脂してしまわないよう、説明書で拭いてよい場所を確認してから掃除しましょう。 [Panasonic：冷蔵庫の掃除](https://panasonic.jp/life/housework/100098.html)

- **霜が増えたら、扉の閉まり方も確認**：自動霜取り式で冷凍室の霜が目立つときは、食品の挟み込みやパッキンのすき間も確認を。少し開いた扉から入った湿気が凍っていることがあり、閉まり方を直さないと掃除しても再発します。 [シャープ：自動製氷の疑問・冷凍室内の露や霜](https://jp.sharp/support/refrigerator/doc/point_seihyo.html)

参考：[Panasonic：冷蔵庫の掃除の準備と方法](https://panasonic.jp/life/housework/100098.html)、[Panasonic：冷蔵庫のお手入れ](https://jpn.faq.panasonic.com/app/answers/detail/a_id/9826/)

### カーテンの洗濯

**負荷の目安：重い**　実作業の目安：20分

頭より高い位置での着脱と、濡れた大きな布の持ち上げがある。

**必要な道具**

- 洗濯機（対象の素材・量に対応するもの）

- 安定した踏み台（必要な場合）

- 洗濯用洗剤

- 大きめの洗濯ネット

- フックを入れる小容器

- 物干し

- 洗濯ばさみ

- 生地が収まる洗いおけ（手洗い指定の場合）

**手順**

1. 洗濯表示で家庭洗濯と機械洗いの可否を確認する。機械で洗う場合は対応・容量も確認し、乾かす場所を確保してから取り外す。

2. ほこりを落とし、フックを外して小容器にまとめる。生地をひだに沿って折り、機械で洗う場合はネットに入れる。

3. 機械洗いできるものは、ほかの洗濯物と分け、表示に合う洗剤・コースで洗い、指定の短い脱水にする。手洗い指定なら、生地が無理なく収まる容器で表示どおりに押し洗い・すすぎ・水切りをする。

4. 洗い終わったら形を整え、表示に合う方法で干す。厚手で重いものは荷重に耐える物干しを使う。レール干しが認められた軽い製品は、レールの耐荷重を確認し、フックを戻してから掛ける。

5. 全体が乾いたことを確認する。物干しで乾かした場合は、フックを戻して元の位置に掛け直す。

**注意事項**

- 椅子や不安定な台に乗らない。無理に手を伸ばさず、安全に届かない高さは人に手伝ってもらう。

- 濡れて重くなったカーテンを弱いレールに掛けない。床や壁に水滴が付いたら拭き取る。

- 乾燥機は縮みや加工の傷みにつながる。明確に許可された製品・条件以外では使わない。

- 水洗い不可のものは家庭で洗わず、表示を持ってクリーニング店に相談する。

**豆知識・手入れのコツ**

- **洗っている間に窓まわりを拭く**：カーテンを外した機会に、安全に届く窓まわりの汚れを拭いておくと、洗ったばかりの生地への汚れ戻りを防げます。 [サンゲツ：カーテン取扱説明書](https://contents.sangetsu.co.jp/doc/manual/%E3%80%90%E3%82%AB%E3%83%BC%E3%83%86%E3%83%B3%E3%80%91%E5%8F%96%E6%89%B1%E8%AA%AC%E6%98%8E%E6%9B%B8.pdf)

- **ほこりはひだの山と束ねた所に集まりやすい**：洗う前のほこり取りは、ひだの山やタッセルで束ねていた部分を重点的に見る。空気中のほこりがたまりやすい場所なので、生地を傷めないブラシや適合する掃除機のブラシでやさしく除くと取り残しを減らせる。 [サンゲツ：カーテンのお手入れ方法](https://www.sangetsu.co.jp/style/curtain_care.html)

参考：[サンゲツ：カーテンのお手入れ方法](https://www.sangetsu.co.jp/style/curtain_care.html)、[ニトリ：自宅でできるカーテンの洗い方](https://www.nitori-net.jp/ec/tips/window-Curtain02/)、[消費者庁：洗濯表示](https://www.caa.go.jp/policies/policy/representation/household_goods/guide/wash_02.html)

6. 乾いた床に平らに敷き直す。しまう場合は湿りが残っていないか再確認し、製品に合うたたみ方・巻き方で収納する。

**注意事項**

- 防水性・ゴム裏面・厚手など、洗濯機が禁止するラグは脱水だけでも入れない。洗濯表示と機械の条件が合わなければ専門店へ相談する。

- 洗濯槽に押し込まない。家庭で安全に扱えない重さや大きさなら作業を中止する。

- ベランダの手すりには掛けず、身を乗り出さない。濡れた床での転倒にも気を付ける。

- 乾燥機はラグと機械の両方が対応する場合だけ使い、温度と容量を守る。

参考：[ニトリ：カーペット・ラグの洗濯方法](https://www.nitori-net.jp/ec/tips/rug-Rug02/)、[シャープ：洗濯機の安全な使い方](https://cgi.jp.sharp/support/safety/washer.html)

### 寝具の乾燥

**負荷の目安：重い**　実作業の目安：10分

布団一式を抱えて運び、広げる・裏返す動作がある。

**必要な道具**

- 布団干し（屋外または室内用）

- 清潔な布

- 布団ばさみ（屋外で必要な場合）

- 布団乾燥機（寝具が対応する場合の代替）

**手順**

1. 寝具の表示で天日干し・陰干し・乾燥機の可否を確認し、適した方法を選ぶ。屋外なら雨や強風の心配が少ない日を選ぶ。

2. 物干しの汚れを拭き、安定と耐荷重を確認する。布団を一枚ずつ運び、製品指定があればカバーを掛けたまま広げる。

3. 表示の方法で干し、途中で表裏を変えて両面に風を通す。布団乾燥機を使う場合は、寝具に合うコースで説明書どおりに設置・運転する。

4. 湿りが残っていないか確認して取り込む。乾燥機を使った場合は終了・停止を確認し、安全に冷ましてから片付ける。

5. 熱や湿気が残らない状態で、寝床に戻すか収納する。収納場所も湿っていないか確かめる。

**注意事項**

- 手すりへの布団掛けや、身を乗り出す作業はしない。風で落下しない、敷地内の安定した干し場所を使う。

- 強くたたかない。側生地や中材を傷めるため、ほこりは必要に応じて吸引清掃で取る。

- すべての寝具が日光や高温に耐えるわけではない。特にウレタン等は、寝具側と乾燥機側の条件が一致する方法を使う。

参考：[西川：布団全般のお手入れFAQ](https://www.nishikawa1566.com/faq/faq_type/faq_type_9)、[西川：日々のおうちお手入れ](https://www.nishikawa1566.com/contents/care/maintenance/)

### 寝具の吸引清掃

**負荷の目安：普通**　実作業の目安：15分

かがんだ姿勢での吸引と、寝具の向きを変える動作がある。

**必要な道具**

- 掃除機

- 布団用ヘッド（掃除機に適合するもの）

- ごみ袋

**手順**

1. 寝具と掃除機の説明を確認する。シーツやカバーを外し、吸引する面を平らに広げる。

2. 掃除機を停止した状態で清潔な布団用ヘッドを付け、ごみ容量に余裕があるか確認する。

3. 表面を区画に分け、ヘッドをゆっくり動かして順に吸う。縫い目や端も、生地を巻き込まないように吸う。

4. 安全に返せる布団は裏面も吸う。重いマットレスは一人で無理に持ち上げず、触れられる面・側面を製品の指示に沿って清掃する。

5. 掃除機を止め、説明書どおりにごみを捨て、ヘッドを手入れして片付ける。乾いた清潔なカバーを戻す。

**注意事項**

- 濡れた寝具や液体は、乾式の掃除機で吸わない。針・ガラス片なども吸い込ませない。

- 吸着して動かない時は無理に引っ張らず、停止して吸引力やヘッドを調整する。

- 吸引清掃は汚れを取り除く作業で、乾燥や洗濯の代わりでも、ダニ等の完全除去を保証する方法でもない。

### 毛布の洗濯

**負荷の目安：重い**　実作業の目安：15分

水を含む毛布の取り出し・運搬・物干しへの持ち上げに力が要る。

**必要な道具**

- 洗濯機（機械洗いに対応する場合）

- 素材に合う洗濯用洗剤

- 毛布用洗濯ネット（機種が指定する場合）

- 洗濯キャップ（機種が指定する場合）

- 洗濯かご

- 耐荷重に余裕のある物干し

- 洗いおけ（手洗いするものが無理なく収まる大きさ）

**手順**

1. 毛布の表示と洗濯機の説明を見て、素材・重量・大きさ・コースが対応するか確認する。肌に直接触れる使い方なら、タオルケット等と同様に汚れや汗を基準に洗う。

2. ごみを取り、気になる部分を許可された洗剤・方法で前処理する。機種指定の形にたたみ、ネットや洗濯キャップが必要なら取り付ける。

3. 洗剤を量り、指定されたコースで洗ってすすぎ・脱水する。手洗いのみ可なら、表示に従って押し洗い・すすぎ・水切りをする。

4. 終了後は早めに取り出して形を整える。広い面に風が通るよう干し、重なる位置を変えながら全体を乾かす。

5. 端や折り目の内側まで乾いたことを確認し、使う場所へ戻す。収納前の洗濯なら、乾いた収納場所へたたんでしまう。

**注意事項**

- 「毛布コース」があっても全素材・全サイズを洗えるわけではない。洗濯不可や容量超過なら専門店へ相談する。

- ネットや洗濯キャップは機種により要否が異なる。自己判断で追加したり、省いたりしない。

- 乾燥機は毛布と機械の両方が対応する場合だけ使う。電気毛布には通常の毛布の手順を流用せず、専用の説明書を確認する。

- 濡れた毛布を無理に一人で持ち上げない。手すりへの外干しは避け、安定した物干しを使う。

**豆知識・手入れのコツ**

- **竿が2本あればM字、1本なら裾をずらす**：つり干しできる毛布は、重さを支えられる2本の竿に渡して中央を少したるませるM字干しにすると、布の間へ風を通しやすい。竿が1本なら両側の裾を少しずらすと、風に触れる面を増やせる。 [ライオン：毛布・タオルケットの洗い方](https://acron.lion.co.jp/items/blanket)

参考：[Panasonic：毛布洗いの容量・入れ方・洗濯ネット](https://panasonic.jp/wash/select/blanket.html)、[西川：日々のおうちお手入れ](https://www.nishikawa1566.com/contents/care/maintenance/)、[西川：夏寝具のお手入れ特集](https://www.nishikawa1566.com/contents/summer_fabric_care/)

### タオルケット等の洗濯

**負荷の目安：普通**　実作業の目安：15分

大きな布を持ち運び、広げて干す動作がある。

**必要な道具**

- 洗濯機（機械洗いに対応する場合）

- 素材に合う洗濯用洗剤

- 大きめの洗濯ネット（指定がある場合）

- 洗濯かご

- 物干し

- 洗濯ばさみ

- 洗いおけ（手洗いするものが無理なく収まる大きさ）

**手順**

1. タオルケット・肌掛けなど対象の表示を確認し、洗濯機の対応素材・容量・コースと照合する。

2. ごみを取り、首元などの汚れは使える洗剤の方法に従って前処理する。引っ掛かった糸を強く引っ張らない。

3. 指定どおりにたたみ、必要なネットを使って洗う。手洗い指定のものは機械洗いにせず、押し洗い後に十分すすぐ。

4. 許可された方法で水を切り、形を整えて干す。布同士が密着しないようにして風を通す。

5. 縁や重なった部分まで乾いたら取り込み、寝床へ戻すか、たたんで乾いた場所に収納する。

**注意事項**

- 肌に直接触れる寝具は、肌に触れにくい毛布の長い周期にまとめない。汗・汚れ・においがあれば予定を待たず洗う。

- 漂白剤・柔軟剤・乾燥機の使用は表示に合わせる。乾燥機は機械側の対応量も確認する。

- 外干しは安定した物干しで行い、ベランダの手すりに掛けたり、身を乗り出したりしない。

参考：[西川：夏寝具のお手入れ特集](https://www.nishikawa1566.com/contents/summer_fabric_care/)、[花王：洗濯表示の意味](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/007/)、[Panasonic：毛布洗いの容量・入れ方・洗濯ネット](https://panasonic.jp/wash/select/blanket.html)

### 枕本体の洗濯

**負荷の目安：普通**　実作業の目安：10分

水を含んだ枕を支え、押し洗い・水切りする動作がある。

**必要な道具**

- 洗濯機（機械洗いに対応する場合）

- 素材に合う洗濯用洗剤

- 洗濯ネット（指定がある場合）

- 洗いおけ（手洗いの場合）

- 乾いたタオル

- 平干し用ネットなどの乾燥場所

**手順**

1. カバーを外し、枕本体の洗濯表示を読む。中材が洗えるかを確かめ、機械洗いの場合は洗濯機でも対応することを確認する。

2. 縫い目の破れや中材が出る口がないか確認する。中材の取り出しは製品が指示する場合だけ行い、指定があればネットに入れる。

3. 機械洗い可なら指定のコースで洗う。手洗い可なら、表示に合う洗剤液でやさしく押し洗いし、水を替えて十分すすぐ。

4. 許可された方法で水を切る。機械脱水できないものは、押して水分を出し、タオルを当てて吸い取る。

5. 形を整えて表示どおりに干し、途中で向きを変える。中心部まで乾いたことを確認してから、乾いたカバーを掛けて使うか収納する。

**注意事項**

- 「カバーが洗える」と「枕本体が洗える」は別。ウレタン・そば殻等は洗えない製品もあるため、素材名だけで判断しない。

- 乾燥機や布団乾燥機の高温コースは、枕と機械の両方が許可する場合だけ使う。

- 表面が乾いていても中が湿っていることがある。押して湿りを確認し、生乾きのまま使ったり収納したりしない。

- 中材を排水口に流さない。破れや中材の流出が見つかったら洗濯を中止する。

参考：[西川：枕の洗濯・お手入れについて](https://www.nishikawa1566.com/faq/faq_type/faq_type_14)、[花王：洗濯表示の意味](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/007/)

### 調理後の片付け

**負荷の目安：普通**　実作業の目安：15分

立った姿勢で食器を洗い、調理台を拭く反復動作がある。

**必要な道具**

- 食器用洗剤

- 食器用スポンジ

- シンク用スポンジ

- 調理台用の布

- 食器用の清潔な乾いた布

- 水切りかご

- キッチンペーパー

- ごみ袋

- 食洗機専用洗剤（食洗機を使う場合）

- 食器洗い乾燥機（使う場合）

**手順**

1. 火を消して調理器具の熱が落ち着くのを待つ間に、食べ残しを片付ける。皿や鍋の大きな汚れ・油は紙で取り、適切に捨てる。

2. 食器用スポンジに洗剤を付け、汚れの少ない食器から洗う。包丁はほかの食器に紛れないよう、刃先を確かめて個別に扱う。

3. 食器・器具を十分すすぎ、水切りかごへ置く。食洗機を使う場合は対応する食器だけを入れ、食洗機専用洗剤で運転する。

4. 調理台と冷めたコンロの汚れを材質に合う方法で拭き取る。洗剤を使った部分は、必要な水拭きで洗剤分も取る。

5. シンクのごみ受けを空にし、シンク用スポンジで軽く洗って流す。水滴を拭き、スポンジをすすいで水を切る。食洗機使用時は、冷却後に機種指定の残さいフィルター清掃を行う。

6. 炊飯器・トースター等を使った回は、保温等の使用を終えて手入れできる状態になってから、各機器の説明に沿って使用後の手入れを行う。食器が乾いたら収納する。布も洗って乾かし、道具とごみを片付ける。

**注意事項**

- 熱い鍋・コンロでやけどをしないよう、手入れ可能な温度まで冷ます。熱い油を排水口へ流さない。

- 包丁を水の張ったおけの底に隠さない。刃を手でなぞらず、安全な置き場所を確保する。

- 食器用と排水口・シンク用のスポンジを分ける。食洗機に手洗い用の食器用洗剤を入れない。

- この項目で済ませた食器洗い・簡単なシンク清掃は重複実施しない。シンクの念入り清掃や未実施の炊飯器手入れまで完了扱いにしない。

**豆知識・手入れのコツ**

- **食洗機に入れる前は、ゴマ・七味もひと手間**：食洗機では、ゴマや七味のような細かい食べかすが、洗浄中に食器へ再付着することがあります。大きな残菜だけでなく、こうした粒も入れる前に軽く流しておくと、洗い直しを減らせます。 [Panasonic：食洗機で食器の汚れが落ちないとき](https://jpn.faq.panasonic.com/app/answers/detail/a_id/26695/)

参考：[花王：食器洗いの手順と片付けのコツ](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/cleaning/116/)、[LIXIL：シンクの日常のお手入れ](https://www.lixil.co.jp/support/clean/kitchen_02_daily.htm)、[ライオン：手洗い用洗剤と食洗機用洗剤の使い分け](https://qa.lion.co.jp/faq/show/215?site_domain=default)

### 靴のお手入れ

**負荷の目安：軽い**　実作業の目安：15分

座って行えるブラシ・布による小さな手作業が中心。

**必要な道具**

- 素材に合う靴用ブラシ

- 柔らかい白い布

- 素材に合う靴用クリーナー（必要な場合）

- 革用クリーム（表革で必要な場合）

- 紙（形を保つために必要な場合）

**手順**

1. 靴の素材とメーカーのお手入れ方法を確認する。取り外せる中敷きを外し、靴の中と靴底の砂・小石を取り除く。

2. 表面のほこりをやさしくブラシで払う。起毛革は専用のブラシで毛並みを整え、表革と同じクリームを塗らない。

3. 水拭き可の布・合成素材は、固く絞った柔らかい布で汚れを拭く。天然の表革は適合するクリーナー等を少量使い、目立たない所で試してから手入れする。

4. 表革で必要な場合は適合するクリームを薄く塗り、余分を拭いて仕上げる。濡れている靴は水分を取り、形を整えて風通しのよい日陰で乾かす。

5. 靴の内側と中敷きが乾いたら元に戻し、湿気の少ない靴箱へしまう。洗わないと落ちない汚れは、丸洗いできる靴だけ別の洗濯手順へ進む。

**注意事項**

- 天然皮革・起毛革などを、布のスニーカーと同じように丸洗いしない。水だけでもシミになる素材がある。

- クリーナーやクリームは素材・色に合うものを使い、強くこすらない。

- 直射日光、ドライヤー、ストーブ等で急いで乾かさない。変形・変色を防ぐため、指定の乾燥方法を守る。

**豆知識・手入れのコツ**

- **磨く回数だけでなく、履かない日を作る**：履き替えがあるなら同じ靴を連日使わず、交互に履いて内部の湿気を逃がす時間を作る。汗の水分を抱えたまま使い続けると、型崩れや部材の傷みにつながるため、表面がきれいでも休ませる意味がある。 [日本靴工業会：靴の取扱い案内](https://jsma.ne.jp/pdf/textbook__3.pdf)

参考：[アシックス：素材別シューズのお手入れ方法](https://www.asics.com/jp/ja-jp/mk/support/help/shoes/care)、[コロンブス：スムースレザーのお手入れ](https://www.columbus.co.jp/smoothleather/)

### 靴の丸洗い

**負荷の目安：普通**　実作業の目安：30分

洗いおけの前での手洗いと、汚れを落とす反復動作がある。

**必要な道具**

- 靴に使える洗剤

- 柔らかいスポンジ

- 柔らかい靴用ブラシ

- 洗いおけ

- 乾いたタオル

- 色移りしにくい白い紙

**手順**

1. メーカーの案内で丸洗い可能と確認できた靴だけを選ぶ。靴ひもと取り外せる中敷きを外し、それぞれの洗い方を確認する。

2. 乾いた状態で、靴底と内側の砂・ごみを取り除く。使う洗剤を目立たない部分で試し、色落ちや変化がないか確認する。

3. 表示に合う水温と洗剤で湿らせ、柔らかいスポンジやブラシでやさしく洗う。洗える靴ひも・中敷きも別に洗う。

4. 洗剤が残らないよう十分すすぎ、タオルで押さえて水分を取る。形を整え、必要なら白い紙を中に入れて支える。

5. 風通しのよい日陰で乾かし、湿った紙は交換する。内側まで乾いたら中敷きと靴ひもを戻し、収納する。

**注意事項**

- 革・起毛革・接着や装飾のある靴など、丸洗い不可の品には行わない。素材が不明ならメーカーに確認する。

- 靴が水洗い可能でも、家庭用洗濯機で洗濯・脱水できるとは限らない。この手順は手洗いを基本にする。

- 熱湯での長時間のつけ置きや強いこすり洗いを避ける。洗剤を付けたまま放置しない。

- 乾燥機・ドライヤー・ヒーター・直射日光で強制乾燥しない。完全に乾くまでは履かない。

### 季節衣類のしまい洗い・収納

**負荷の目安：普通**　実作業の目安：45分

衣類の出し入れ・運搬と、かがむ・腕を上げる動作がある。

**必要な道具**

- 洗濯機（対象の素材・量に対応するもの）

- 洗濯用洗剤

- 洗濯ネット（必要な衣類用）

- 洗濯かご

- ハンガー

- 物干し

- 乾いた布

- 収納ケース

- 衣類用防虫剤（必要な場合）

**手順**

1. しまう衣類を集め、まだ使うものと分ける。ポケットを空にし、シミ・傷み・洗濯表示を確認して、家庭で洗うものと専門店に頼むものに分ける。

2. 襟・袖・脇などの汚れを、使える洗剤の方法に従って前処理する。衣類ごとの表示と洗濯機の対応条件に合わせ、無理のない量に分けて洗う。

3. 洗い終えた衣類は表示に合う方法で乾かす。クリーニングから戻った衣類は持ち帰り用のポリ包装を外し、状態を確かめて湿気を逃がす。

4. 収納ケースや棚のほこりを取り、乾いた状態にする。衣類の厚い部分まで乾いたことを確認し、型崩れしにくいようにたたむかハンガーに掛ける。

5. 詰め込み過ぎずに収納する。防虫剤を使う場合は、対象素材・収納容積・使用量・置き場所の表示に従い、入れた日が分かるようにする。

**注意事項**

- 短時間しか着ていなくても、汗や汚れが残ったまま長期収納しない。通常洗濯で済ませた工程は繰り返さなくてよい。

- 家庭洗濯不可の衣類を自己判断で水洗いしない。装飾・接着・特殊加工の付記も確認する。

- 異なる種類の防虫剤を、併用できると確認せず混ぜない。衣類への直接接触の可否も製品表示で確認する。

- 収納ケースを一度に重くし過ぎない。高い棚には重い箱を無理に上げず、持ち運べる量に分ける。

**豆知識・手入れのコツ**

- **防虫剤は底に埋めない**：引き出し・衣装ケース用の防虫剤は、製品の指定に従って衣類の一番上へ置く。一般的な揮散型は成分が上から下へ広がるため、衣類の底に埋め込むより行き渡りやすい。 [エステー：防虫剤の使い方を解説](https://products.st-c.co.jp/column/12815/)

- **開放ラックでは防虫剤の種類を変える**：ケース用の揮散型防虫剤を、扉のないハンガーラックにただ置いても成分が逃げやすい。開放した場所で保管する衣類には、その使い方に対応した防虫カバーなどを選ぶと、収納場所と薬剤のミスマッチを避けられる。 [エステー：防虫剤の使い方を解説](https://products.st-c.co.jp/column/12815/)

参考：[ライオン：衣替え時の洗濯・収納のコツ](https://lidea.today/articles/922)、[エステー：クリーニング後の衣類収納の注意点](https://products.st-c.co.jp/plus/question/9989/)、[花王：洗濯表示の意味](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/007/)、[エステー：防虫剤の種類と併用の注意点](https://products.st-c.co.jp/plus/question/10208/)

### アイロンがけ

**負荷の目安：普通**　実作業の目安：10分

アイロンを支え、衣類を広げながら腕を繰り返し動かす。

**必要な道具**

- 衣類用アイロン

- 安定したアイロン台

- 清潔なあて布（指定がある場合）

- ハンガー

- 給水用容器（スチームを使う場合）

**手順**

1. 衣類のアイロン表示と付記を確認し、使用できる温度・スチーム・あて布の要否を決める。アイロン台を平らで安定した場所に置く。

2. 給水は機器の説明書に従って行い、衣類に合う温度に設定する。複数の衣類は低温指定のものから始める。

3. シャツは襟・肩・袖口などの小さい部分から、袖・胴体の広い部分へ進める。布を平らに整え、同じ所にアイロンを止めず動かす。

4. 仕上がった衣類をハンガーに掛け、熱と湿気を逃がす。冷めて乾いてから収納する。

5. アイロンの電源を切り、プラグを抜く。その後の冷却・排水は、機種の説明書が指定する順序で行う。触れたり倒したりしない安全な場所で冷まし、十分に冷えたことを確認して片付ける。

**注意事項**

- 着たままアイロンをかけない。熱いかけ面や蒸気に手を近づけず、人や動物へ向けない。

- ボタン・ファスナー・プリント・接着部分へ直接押し当てない。混紡は低い方の許容温度に合わせる。

- 作業中に手を離すときは、機種指定の安定した置き方にする。その場を離れるときは電源を切り、プラグを抜く。

- 抜栓後もしばらく高温が続く。コードが引っ掛からない位置で冷まし、熱いまま一般の収納箱へ入れない。

**豆知識・手入れのコツ**

- **ハンカチは伸びにくい方向へかける**：ハンカチを正方形に仕上げたいときは、アイロンをかける前に生地を軽く引いて伸びにくい方向を確かめ、その方向に沿って動かします。布を無造作に押し広げるより、形のゆがみを抑えやすくなります。 [Panasonic：アイロンのかけ方入門・アイテム別](https://panasonic.jp/iron/howto/item.html)

参考：[花王：ワイシャツのアイロンがけ](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/014/)、[Panasonic：アイロンの温度と衣類の絵表示](https://jpn.faq.panasonic.com/app/answers/detail/a_id/11605/)、[日立：スチームアイロン使用後の収納](https://kadenfan.hitachi.co.jp/support/iron/q_a/a12.html)

### レンジフードの日常部品の清掃

**負荷の目安：普通**　実作業の目安：15分

腕を上げて部品を支え、油汚れを洗う作業がある。

**必要な道具**

- 厚手の滑りにくい手袋

- 柔らかいスポンジ

- 柔らかい布

- 部品に使える台所用中性洗剤

- 取り外した部品を置く敷物

- 安定した踏み台（必要な場合）

**手順**

1. コンロとレンジフードの運転を止め、熱が冷めるまで待つ。レンジフードの電源プラグを抜くか、対応するブレーカーを切る。

2. 手袋を着け、下にある調理器具を片付ける。説明書で外せる部品を確認し、整流板などを手で支えながら指定の順序で外す。

3. 油受けにたまった油を布などに吸わせて取り除く。整流板は洗剤を含ませた布で拭き、水拭きして洗剤を残さない。

4. 水洗いできるフィルターや油受けは、指定の濃さの中性洗剤と柔らかいスポンジで洗う。つけ置きは説明書で認められた部品・時間だけにする。

5. 洗った部品を十分にすすいで水気を取り、乾かす。向きと固定箇所を確認して元に戻し、電源を復旧して異音やがたつきがないか確かめる。

**注意事項**

- コンロや不安定な椅子の上には乗らない。無理なく届かない場合は作業をやめる。

- スイッチ・モーター・配線に水や洗剤をかけない。本体へ洗剤を直接スプレーしない。

- アルカリ性洗剤や研磨剤を自己判断で使わない。食洗機に入れられるかも部品ごとに確認する。

- 整流板は大きく重い場合がある。片手で安全に支えられない構造や、外し方が分からない部品は無理に外さない。

**豆知識・手入れのコツ**

- **掃除しても吸い込みが悪いときは、横風も確認**：フィルターをきれいにしても油煙が逃げる場合は、エアコンなどの風がフードへ直接当たっていないか確認を。横からの風で油煙が流されるためで、特に上昇気流の弱いIHでは風向きの影響を受けやすくなります。 [FUJIOH：よくあるご質問・吸い込みが悪い](https://www.fujioh.com/support/faq/faq-fujioh)

参考：[タカラスタンダード：レンジフードのお手入れ方法](https://qa.takara-standard.co.jp/fa/pblc/web/knowledge1211.html)、[FUJIOH：レンジフードを安全に正しくお使いいただくために](https://www.fujioh.com/support/safe.html)

### レンジフードのファン清掃

**負荷の目安：重い**　実作業の目安：30分

高い位置でファンを支えて着脱し、細かな羽根を洗う。

**必要な道具**

- 厚手の滑りにくい手袋

- 柔らかいスポンジ

- 柔らかい布

- ファンに使える台所用中性洗剤

- ファンを置く敷物

- 安定した踏み台（必要な場合）

**手順**

1. 説明書で、使用者がファンを外して洗える機種か確認する。清掃不要・取り外し不可のファンはこの作業の対象にしない。

2. コンロとレンジフードを止めて冷まし、電源プラグを抜くか対応するブレーカーを切る。手袋を着け、周囲の物を片付ける。

3. 説明書の順序で手前の部品を外す。ファンを支えながら固定具を指定の方法で解除し、ゆっくり取り出す。部品の向きを覚えておく。

4. 外したファンを指定の中性洗剤と柔らかいスポンジで洗う。つけ置きが認められている場合だけ、指定の水温・時間を守って行う。

5. 洗剤をよくすすぎ、羽根の間の水気を取って十分乾かす。逆の順序で組み立て、固定具と手前の部品が確実に付いているか確認する。

6. 電源を復旧して短く運転し、普段と違う振動・音・がたつきがないか確認する。異常があればすぐに停止する。

**注意事項**

- 固着したファンやねじを力任せに外さない。安全に持ち上げられない場合は専門業者に依頼する。

- 羽根を曲げたり、落としたりしない。金属たわしで強くこすらない。

- モーターなどの電気部品は洗わない。ファンを外したまま運転しない。

- 調理台やコンロの上には乗らない。自動洗浄機種の内部を、一般的な外し方で分解しない。

### 洗濯機の糸くずフィルター清掃

**負荷の目安：軽い**　実作業の目安：2分

小さな部品のごみ取りが中心で、強い力を使わない。

**必要な道具**

- ごみ袋

- 柔らかいブラシ（説明書で使用できるもの）

- 水気を取る布

**手順**

1. 洗濯が終わって槽が止まったことを確認する。衣類を出し、電源を切ってから、槽内の糸くずフィルターを説明書の外し方で取り出す。

2. ケース型はふたを開き、ネット型は指定の向きに返して、糸くずをつまんでごみ袋に捨てる。

3. 水洗いできるフィルターをすすぐ。目詰まり部分は、使用が認められた柔らかいブラシで軽く洗う。

4. 水気を切り、ケースやふたを元どおりに閉める。取り付け位置に戻して、留め具が確実にはまったことを確認する。

**注意事項**

- これは槽の中に付いているフィルターの手順。前面下部の排水フィルターには適用しない。

- フィルターを外した穴へ小物を落とさない。ネットや留め具の破れ・割れがあれば適合部品へ交換する。

- フィルターを外したまま洗濯しない。洗濯の手順に含めた場合、この作業の2分を別に足さない。

**豆知識・手入れのコツ**

- **糸くずが少ない＝よく取れている、とは限らない**：フィルターに糸くずがほとんどないのに衣類には付くときは、目詰まりだけでなく詰め込みすぎも確認。洗濯物が動きにくいと糸くずがフィルターまで届きにくいため、対応する機種では量を減らすなど、説明書の対処法を試せます。 [三菱電機：糸くずが衣類に付着／フィルターにたまらない](https://faq01.mitsubishielectric.co.jp/faq/show/585?site_domain=default)

参考：[日立：タテ型洗濯機の糸くずフィルターのお手入れ](https://kadenfan.hitachi.co.jp/support/wash/q_a/a72.html)

### 洗濯機の排水フィルター清掃

**負荷の目安：普通**　実作業の目安：5分

低い位置でかがみ、残水を受けながら部品を着脱する。

**必要な道具**

- 浅い水受け容器

- 吸水用の古いタオル

- 柔らかいブラシ

- ごみ袋

**手順**

1. 型番の説明書で排水フィルターの手順を開く。運転中は触らず、温水を使った直後は十分冷ます。指定の排水・脱水操作で槽内の水を抜き、運転が止まったことを確認する。

2. 電源は説明書が指定する状態にする。残水の警告を確認するために電源を入れておく機種もある。フィルターの下にタオルと浅い容器を置く。

3. 残水排出用ホースがある機種は指定の方法で残水を抜く。つまみを少し緩めて排水する機種は、説明書で指定された位置までゆっくり動かし、水を受ける。

4. 水が出続けないことを確認してから、指定の方法でフィルターを取り出す。糸くずをごみ袋に捨て、水洗いできる部分を柔らかいブラシで洗う。

5. 取り付け口とパッキンに付いたごみを取り、パッキンのずれや傷を確認する。フィルターを指定の向き・締め位置まで戻し、残水ホースがあれば栓も確実に戻す。

6. 周囲の水を拭き、カバーを閉める。説明書指定の確認操作、または次回の運転開始時に、フィルター周辺から水が漏れないか確かめる。

**注意事項**

- 槽内に水が残っている状態で一気に引き抜かない。多量の水が出る、残水警告が鳴る、排水できない場合はそれ以上開けず、説明書の対処手順を確認する。

- 熱い水が残る可能性がある。冷却・残水処理の方法が確認できない場合は開けない。

- パッキンが外れている、傷がある、確実に締まらない場合は運転しない。メーカーへ相談する。

- 残水を排水口や電源部へ飛ばさない。濡れた手でプラグを触らない。

参考：[Panasonic：ドラム式洗濯機の排水フィルターのお手入れ](https://jpn.faq.panasonic.com/app/answers/detail/a_id/76/)

### 洗濯機の乾燥フィルター清掃

**負荷の目安：軽い**　実作業の目安：2分

軽いフィルターのほこり取りが中心。

**必要な道具**

- ごみ袋

- 柔らかい布

- 水気を取る乾いた布

**手順**

1. 乾燥運転が完全に終了し、部品が冷めてから電源を切る。説明書で手入れする乾燥フィルターの位置と外し方を確認する。

2. 取り外せるフィルターをゆっくり抜き、外せるカバーがあれば開く。付いたほこりをつまむか、よく絞った柔らかい布で取り、ごみ袋へ捨てる。

3. 目詰まりが残る場合は、水洗いできると明記された部品だけを指定の方法で洗い、十分に乾かす。

4. 取り付け口は、説明書で触れてよい表面だけのほこりを取る。奥の乾燥経路には手や道具を入れない。

5. フィルターとカバーを正しい向きで確実に戻す。お手入れ表示の解除が必要な機種は、説明書に沿って操作する。

**注意事項**

- 乾燥を使った回の手順に含める。洗濯のみの回へ一律に追加したり、親の洗濯時間と2分を二重計上したりしない。

- 薄い網をこすりすぎない。洗った部品を濡れたまま取り付けない。

- 歯ブラシなどを内部に差し込まない。落とした道具を取るために本体を分解しない。

- 自動清掃・サイクロン方式などは構造が異なるため、その機種の対象部品と手入れ方法を優先する。

**豆知識・手入れのコツ**

- **掃除しても乾きにくいときは「上に置いた物」も**：フィルターを掃除しても乾きが悪いときは、洗濯機の上のタオルやかごが給排気口をふさいでいないかも確認。天面に給排気口があるドラム式では、物を置くだけでも空気の通りが悪くなり、乾燥効率が落ちることがあります。 [Panasonic：乾かない・乾燥フィルターが濡れる・水がたまるときは](https://jpn.faq.panasonic.com/app/answers/detail/a_id/31639/)

参考：[Panasonic：洗濯機の定期的なお手入れ](https://panasonic.jp/wash/contents/care.html)、[Panasonic：乾燥フィルター・乾燥経路のお手入れ](https://jpn.faq.panasonic.com/app/answers/detail/a_id/77)

### 洗濯槽のお手入れ

**負荷の目安：軽い**　実作業の目安：5分

洗浄剤の準備と操作が中心で、長い運転中は作業しない。

**必要な道具**

- 機種と選択コースに適合する洗濯槽クリーナー（必要なコースのみ）

- 薬剤の表示で指定された手袋

- 柔らかい布

**手順**

1. 説明書で槽洗浄コース、対応する洗浄剤、使用量、投入するタイミングを確認する。洗浄剤を使わない短時間コースと取り違えない。

2. 衣類をすべて出し、必要なフィルターが付いているか確認する。換気を確保し、給水が必要な機種は水栓を開く。

3. 説明書の順番で槽洗浄を選ぶ。指定のタイミングで洗浄剤を入れ、ふた・ドアを閉めて開始または再開する。先に入れない指定の機種では、投入の合図を待つ。

4. すすぎや乾燥を含め、選んだコースが最後まで終了するのを待つ。運転中にドアを無理に開けたり、洗剤を追加したりしない。

5. 終了後に槽内やドアの縁を確認する。残ったごみや水滴は、説明書で触れてよい範囲を布で取り、フィルターにごみがたまっていたら該当の手入れを行う。

**注意事項**

- 「洗濯槽用」でも全機種・全コースには使えない。ドラム式と縦型の適合、薬剤の種類、容量を両方の表示で確かめる。

- 別の洗剤・漂白剤・酸性の製品などを混ぜない。薬剤の換気・保護具・取り扱いの注意を守る。

- 運転やつけ置きが数時間かかっても、目安5分は準備・操作・終了確認などの手作業だけを指す。

- 機器のお手入れ表示や汚れ・においが出たら、予定の周期を待たず確認する。

**豆知識・手入れのコツ**

- **「防カビ」と「今ある汚れを落とす」は別**：衣類用洗剤・漂白剤の「洗濯槽の防カビ」という表示は、すでに付いたカビや汚れまで落とせる意味とは限りません。予防用の製品を使っていても、槽に汚れが出たら、機種に適合する槽洗浄コース・専用クリーナーでの手入れは別に考えましょう。 [花王：衣料用漂白剤の洗濯槽防カビ効果と槽洗浄の違い](https://www.kao.com/jp/qa/detail/31736/)

参考：[日立：ドラム式洗濯機の槽洗浄コース](https://kadenfan.hitachi.co.jp/support/wash/q_a/a45.html)、[日立：槽洗浄・槽乾燥の頻度](https://kadenfan.hitachi.co.jp/support/wash/q_a/a67.html)

### エアコンフィルターの清掃

**負荷の目安：普通**　実作業の目安：10分

腕を上げてフィルターを着脱し、安全な足場も用意する。

**必要な道具**

- 掃除機

- 柔らかい布

- 安定した踏み台（必要な場合）

- 床を保護する敷物

**手順**

1. 運転と自動お掃除が終わるのを待ち、電源プラグを抜く。プラグ式でない機種は説明書で指定された電源遮断を行う。

2. 安定した足場を用意する。説明書の方法で前面パネルを開け、網状のエアフィルターを無理に曲げずに取り出す。

3. フィルターのほこりを掃除機で優しく吸い取る。付属の小さな脱臭・空気清浄フィルターは別部品として扱い、それぞれの洗える・洗えないを確認する。

4. 水洗いが認められたエアフィルターで汚れが残る場合だけ、水で洗う。洗剤が必要なら、説明書で認められたものを指定の濃さで使い、よくすすぐ。

5. 水気を取り、日陰で十分に乾かす。フィルターを正しい向きで戻し、前面パネルを確実に閉める。

6. 電源を戻す。必要な機種はお手入れ表示をリセットし、正常に運転することを確認する。

**注意事項**

- 本体内部へ水や市販の洗浄スプレーを入れない。内部のカビや汚れはメーカー・専門業者に相談する。

- 熱交換器の金属部分には触らない。パネルや自動お掃除の機構を力任せに動かさない。

- フィルターは熱湯やドライヤーで乾かさず、濡れたまま戻さない。

- 足場が不安定、腕を伸ばしても届かない場合は自分で行わない。自動清掃機種は汚れや表示に応じた手入れを優先する。

**豆知識・手入れのコツ**

- **自動お掃除が集めたほこりの行き先も確認**：フィルターの自動お掃除機能には、集めたほこりを本体のダストボックスにためるタイプがあります。網だけを見て終わらず、説明書でほこりの行き先とダストボックスの手入れ方法を確認すると、見えないため込みに気づけます。 [Panasonic：換気のコツとエアコンのフィルター・内部の正しい掃除方法](https://panasonic.jp/life/air/170011.html)

- **停止後の送風は、内部を乾かしていることも**：冷房・除湿を止めたあとも風が出るのは、内部クリーン運転で結露を乾かしているための場合があります。対応機種ではこの運転を途中で止めず、終了を待ってからフィルター清掃の電源遮断へ進むと、内部の乾燥も済ませられます。 [ダイキン：エアコン掃除の困りごとと対処法](https://www.daikin.co.jp/air/life/laboratory/aircon-clean)

参考：[Panasonic：エアコンのお手入れ方法](https://jpn.faq.panasonic.com/app/answers/detail/a_id/9890/)、[三菱電機：エアフィルターのお手入れ](https://faq01.mitsubishielectric.co.jp/faq/show/715?site_domain=default)

### 食洗機の残さいフィルター清掃

**負荷の目安：軽い**　実作業の目安：2分

**必要な道具**

- ごみ袋

- 柔らかいブラシ

- 水滴を拭く布

**手順**

1. 運転が終わり、説明書指定の冷却時間が過ぎてから作業する。電源を切り、抜栓などが指定されている機種はその手順を守る。

2. 食器を取り出し、必要ならかごを外す。説明書の方法で残さいフィルターを持ち上げ、食べかすを庫内へ落とさず取り出す。

### 食洗機の庫内等のお手入れ

**負荷の目安：普通**　実作業の目安：10分

庫内へかがみ込み、ドアの縁や部品を手で拭く。

**必要な道具**

1. 運転終了後、説明書指定の時間を置いて冷ます。電源を切り、手拭き前の抜栓などは機種の指示に従う。食器と、取り外してよいかごを出す。

2. 残さいフィルターのごみを捨てて水洗いする。ノズルなどは使用者が外せると記載された部品だけを外し、説明書の方法で詰まりを取り除く。

3. よく絞った柔らかい布で、庫内、ドアの縁、パッキンが当たる面を拭く。取れたごみを集め、洗った部品とかごを正しく戻す。

### 加湿器タンクの手入れ

**負荷の目安：軽い**　実作業の目安：2分

小さなタンクの持ち運びとすすぎが中心。

**必要な道具**

- 水道水

- 柔らかい布

**手順**

1. 運転を止め、電源プラグを抜く。加熱する機種は冷めてからタンクを外す。

2. 残った水を捨て、新しい水を少量入れて、ふたを閉めて軽く振り洗いする。外せないタンクは説明書の排水・すすぎ方法を使う。

3. すすぎ水を捨て、ふたや給水口の汚れを確認する。ぬめりが残るときは、機種指定のお手入れを追加する。

4. 使い続ける場合は新しい水道水を入れ、ふたを閉める。外側の水滴を拭いて戻す。使わないときは空にして乾かす。

**注意事項**

- 古い水に継ぎ足さず、使用日は毎日入れ替える。

- 運転用の水にアロマオイル・除菌剤・洗剤などを自己判断で加えない。

- 本体や電源部分には水をかけない。大きなタンクは満水で無理に運ばず、持てる量に調整する。

**豆知識・手入れのコツ**

- **加湿には「飲んでおいしい水」が最適とは限らない**：水道水指定の加湿器では、浄水器の水やミネラルウォーターに置き換えず、指定された飲用の水道水を使います。水道水は一般に塩素処理されていて雑菌が増えにくいことが、指定の理由です。飲み水としての好みと機器に適した水は別です。 [Panasonic：加湿空気清浄機で使用できる水は](https://jpn.faq.panasonic.com/app/answers/detail/a_id/15038/)

### 加湿器のまとまった手入れ

**負荷の目安：普通**　実作業の目安：15分

水を捨てながら複数の部品を持ち替え、洗って戻す。

**必要な道具**

- 柔らかいスポンジ

- 柔らかい布

- 洗いおけ

- 機種指定の洗浄剤（必要な場合のみ）

**手順**

1. 説明書で洗える部品と洗浄方法を確認する。停止・抜栓し、熱い部分が冷めてから残水を捨てる。

2. トレー・加湿フィルターなど、使用者が外せる部品だけを取り出す。取り付け方向を確認しておく。

3. トレーの汚れは水と柔らかいスポンジで落とし、加湿フィルターは指定方法でやさしく洗う。

4. 水あかやにおいが残る場合だけ、適合する洗浄剤を指定量・指定時間で使い、十分にすすぐ。

5. 本体は水をかけず、布で清掃する。各部品を指定どおり水切り・乾燥し、元の向きに戻す。収納前は内部まで十分に乾かす。

**注意事項**

- クエン酸や漂白剤が使える部位は機種で異なる。すべての部品に同じ洗浄液を使わない。

- 洗浄剤どうしを混ぜない。別の洗浄剤へ替えるときも、前の液を十分に洗い流す。

- フロートなどの小部品を無理に外さない。フィルターをねじったり、乾燥機で乾かしたりしない。

**豆知識・手入れのコツ**

- **白や赤茶色の固まりは、水の成分のことも**：加湿フィルターに付く白色や赤茶色の固まりは、水道水のカルシウムなどが残ったものの場合があり、色だけでカビと決めつけないのがポイント。説明書の水あか向け手入れを選び、清掃してもにおいや加湿量の低下が続く場合は、フィルターの交換目安も確認しましょう。 [シャープ：加湿フィルターのお手入れ](https://jp.sharp/support/humid_con/mt_doc/filter_humi_care_ex30.html)

### 空気清浄機のお手入れ

**負荷の目安：軽い**　実作業の目安：5分

軽いフィルターのほこり取りと外装の拭き取りが中心。

**必要な道具**

- 掃除機

- 柔らかい布

**手順**

1. 運転を止めて電源プラグを抜き、説明書でプレフィルターの位置を確認する。

2. カバー表面のほこりを吸い取り、外せるカバーとプレフィルターを静かに外す。

3. プレフィルターのほこりを、網を強く押さずに掃除機で取る。

4. 外装を布で拭く。水洗いが許可された部品だけを必要に応じて洗い、十分に乾かす。

5. フィルターの向きとカバーの固定を確認して戻す。加湿タンクやセンサーは、それぞれの指定周期で別に手入れする。

**注意事項**

- 集じん・HEPA・脱臭フィルターは、水洗いできるとは限らない。表示を確認するまで洗わない。

- 交換専用のフィルターを洗って再使用しない。フィルター表面を強くこすらない。

### 電気ケトル・電気ポットの水あか洗浄

**負荷の目安：普通**　実作業の目安：5分

水の入った容器を持ち上げ、傾けて排水する。

**必要な道具**

- 機種に適合する水あか用洗浄剤

- 水

- 柔らかい布

**手順**

1. 説明書で洗浄剤・使用量・水量・操作方法を確認する。手で触る前は抜栓し、熱湯が残っていれば冷ます。

2. 指定された洗浄剤と水を、説明書の順序で内容器に入れる。満水線を超えないようにする。

3. ふたを閉め、必要な場合だけ電源をつなぎ、指定の洗浄運転や湯沸かしを行う。

4. 指定時間が過ぎたら停止し、プラグを抜く。蒸気と湯の温度を確かめ、安全に扱える状態で指定の方向から排水する。

5. 説明書どおりにすすぐ。水だけを沸かして捨てる指定がある機種は、その工程も行う。

6. 外側と接続部の水気を拭き取り、十分に乾いてから電源台などに戻す。

- クエン酸を使えるとは限らない。洗剤量や放置時間を別機種の手順から流用しない。

- 洗浄液は飲まない。洗浄中と分かるようにし、ほかの洗浄剤と混ぜない。

- 本体・電源台を水に沈めない。蒸気口や注ぎ口を顔・手に向けず、重いポットは無理に持ち上げない。

**豆知識・手入れのコツ**

- **水しか入れなくても、白い汚れはたまる**：内容器の白いざらつきは、水に含まれるミネラル分が残った水あかの場合があります。洗剤で油汚れを落とすのとは別の手入れなので、強く削るのではなく、機種に指定された水あか洗浄を選びましょう。 [象印：電気ケトルの掃除](https://www.zojirushi.co.jp/kakushiaji/article/000019/)

### 自動製氷機の製氷皿等の清掃

**負荷の目安：軽い**　実作業の目安：10分

小さな製氷皿を取り外してすすぐ作業。

**必要な道具**

- 水

- 清潔な布（周囲の水滴用）

**手順**

1. 製氷皿を外して洗える機種か、説明書で確認する。取り外せない機種はこの作業を行わない。

2. 指定の製氷停止操作をし、取り外せる状態になったことを確認する。ロックがあれば解除する。

3. 製氷皿を取り出し、水でやさしくすすぐ。洗い残しが気になっても、表面をこすって傷つけない。

4. 水を切って皿を奥まで戻し、ロックを確実にかける。周囲に落ちた水滴を拭く。

5. 説明書どおり製氷停止を解除し、取り付け状態と表示を確認する。

**注意事項**

- 停止操作や取り外し可否が不明なまま、製氷部に手を入れたり皿を引っ張ったりしない。

- 製氷皿はスポンジ・たわしでこすらず、洗剤も自己判断で使わない。皿に直接水を張って戻さない。

- 外せない機種には専用の製氷清掃運転がある場合がある。この取り外し手順では代用しない。

**豆知識・手入れのコツ**

- **氷が少ないのに止まるなら、氷の山を確認**：検知レバーで氷の量を測る機種では、ケースの一か所に氷が山積みだと、まだ空きがあっても満杯と判定されることがあります。普段から説明書に沿って氷の偏りをならし、スコップは指定位置に戻しましょう。 [シャープ：氷がケースいっぱいにならない理由](https://jp.sharp/support/refrigerator/doc/point_seihyo.html)

### 浴室のカビ取り

**負荷の目安：普通**　実作業の目安：15分

局所への塗布・すすぎと、低い場所の作業。

**必要な道具**

- 対象の材質に使えるカビ取り剤

- ゴム手袋

- 保護眼鏡

- マスク（製品表示に従う）

**手順**

1. カビがある時だけ行う。設備と薬剤の説明で、使える場所・量・放置時間を確認する。

2. 換気し、指定の保護具を着ける。先に使った洗剤を十分に水で流し、薬剤が指定する乾湿状態に整える。

3. 手の届く低い範囲に、表示どおりの量を使う。垂れた薬剤が対象外の金属や鏡に付いたら、すぐ水で流す。

4. 指定時間を守って十分にすすぐ。洗剤が残っていないことを確認し、道具を洗って換気を続ける。

**注意事項**

- カビ取り剤は単独で使う。酸性洗剤・クエン酸・酢・アルコールなどを併用せず、他の薬剤が残る場所にも使わない。

- 肩より高い場所へ直接スプレーしない。天井や広範囲のカビは無理に処置しない。

- 目や喉への刺激、気分の悪さを感じたら中止してその場を離れる。症状が続く場合、または誤って薬剤を混ぜて刺激や不調が出た場合は、直ちに医療機関へ相談する。

**豆知識・手入れのコツ**

- **「防カビ」と「黒い色を落とす」は別の役割**：防カビ剤には、黒カビの発生を抑えても、すでに付いた黒い汚れを落とす効果はない製品があります。「黒ずみを落としたい」のか「再発を抑えたい」のかで用途表示を見分けると、使ったのに色が残ったという行き違いを防げます。 [ライオン：ルックプラス おふろの防カビくん煙剤](https://look.lion.co.jp/bath/boukabi/)

参考：[LIXIL：浴室のカビのお手入れ](https://www.lixil.co.jp/support/manual/bathroom/ax-af/manual/-Care/Care-Yogore-Kabi-v001.htm)、[ジョンソン：洗剤の混合・続けて使う時の注意](https://scjcatalog.johnson.co.jp/life/souji_jyutsu/knowledge_05.html)、[花王：カビ取り剤などで気分が悪くなった時](https://www.kao.com/jp/qa/detail/21886/)

### 頑固な水あか落とし

**負荷の目安：普通**　実作業の目安：15分

小さな汚れを確かめながら、繰り返し手入れする。

**必要な道具**

- 設備メーカーが指定する水あか用洗浄剤

- 柔らかいスポンジ

- 柔らかい布

- ゴム手袋

**手順**

1. 通常の清掃で落ちない水あかがある時だけ行う。鏡・蛇口の材質やコーティングを確認する。

2. 説明書で、その部位に使える洗浄剤と道具を選ぶ。判断できない場合は作業せずメーカーへ確認する。

3. 先の洗剤を十分に除き、指定された方法・量・時間で小さな範囲から処置する。力任せにこすらない。

4. 水で洗い流すか、清潔な布で十分に水拭きして薬剤を除く。乾いた布で水滴を取り、傷やくもりが出ていないか確かめる。

**注意事項**

- クエン酸・酢・研磨剤を、どの鏡や蛇口にも使えるものとして扱わない。くもり止め加工などを傷める場合がある。

- 塩素系製品と酸性のものを併用しない。別の薬剤を足したり、残留したまま次を使ったりしない。

- 黒いしみや表面の傷は水あかではない場合がある。落ちないからと繰り返し削らず、メーカーへ相談する。

**豆知識・手入れのコツ**

- **白いザラザラは、全部同じ汚れではない**：白い汚れには、水道水の成分が残った水あかのほか、石けんや皮脂と水中の金属成分が結び付いた「金属石けん」もあります。見た目だけでクエン酸や研磨剤に決めず、設備の説明書で汚れと素材に合う方法を確認しましょう。 [LIXIL：汚れのきほん](https://owners.lixil.co.jp/housecaring/dailycleaning/yogore)

参考：[LIXIL：浴室の鏡の種類別お手入れ](https://faq.lixil.co.jp/ユニットバス（風呂）の鏡をお手入れする方法-626cd6cc2cb4bd00237e21a3)、[ジョンソン：洗剤の混合・続けて使う時の注意](https://scjcatalog.johnson.co.jp/life/souji_jyutsu/knowledge_05.html)

### 排水トラップ内部・排水管のお手入れ

**負荷の目安：普通**　実作業の目安：10分

低い場所で、部品の着脱と汚れ取りを行う。

**必要な道具**

- 設備に適合する中性洗剤

- 排水口用の柔らかいブラシ

- ゴム手袋

- ごみ袋

- 適合する配管洗浄剤（必要時のみ）

- 保護眼鏡（薬剤表示で指定されている場合）

**手順**

1. 浴室・洗面台・シンクのうち1か所を選ぶ。説明書で、使用者が取り外せる部品と清掃方法を確認する。

2. ごみ受けを外してごみを回収する。外してよい部品だけを、向きを覚えながら外す。

3. 部品と手の届くトラップ内を、適合する中性洗剤とブラシで洗い、十分にすすぐ。

4. 部品を元どおりに戻して水を流し、水漏れや排水不良がないか確かめる。

5. 配管の薬剤洗浄は必要な場合だけ別工程にする。換気し、指定の保護具を着け、適合する専用品を使う。先の洗剤を十分に水で流してから、表示の量・時間・すすぎ方法を守る。

**注意事項**

- 床下・収納内の配管や接続ナットは分解しない。ごみを奥へ押し込まない。

- 配管洗浄剤は他の洗剤と併用しない。残っている薬剤が分からない場合は使わない。生ごみや熱湯も加えない。

- 水が流れない、逆流する、水漏れする場合は薬剤を追加せず、管理会社や専門業者へ相談する。

**豆知識・手入れのコツ**

- **長く留守にした後のにおいは、封水切れかも**：排水トラップにたまる水は、下水のにおいを遮るふたの役割があります。長期間使わなかった後に臭う場合は、この水が蒸発していることもあるため、詰まりや水漏れがなければまず水を流し、それでも続く場合は管理会社などへ相談しましょう。 [新座市：排水溝の臭気が気になるのですが](https://www.city.niiza.lg.jp/faq/soshiki/page/faq-haisuikou-nioi.html)

参考：[大和ハウス：排水トラップの手入れ](https://www.daiwahouse.co.jp/jutaku/tebiki/room/kitchen.html)、[LIXIL：排水管の手入れ・機種ごとの違い](https://www.lixil.co.jp/support/clean/kitchen_02_regular.htm)

### 部屋の床だけの清掃

### 家具・棚のほこり取り

**必要な道具**

### 浴槽だけの清掃

**負荷の目安：普通**　実作業の目安：5分

浴槽の底や側面へ手を伸ばすため、腰を曲げる姿勢がある。

**必要な道具**

- 柔らかい浴室用スポンジ

- 浴室用中性洗剤

- ゴム手袋

- 乾いた布

- 柄付きスポンジ（底へ無理なく届かない場合）

**手順**

1. 浴槽のお湯を抜き、換気する。床の物をよけ、足元の安全を確かめる。

2. 浴槽をシャワーですすぎ、柔らかいスポンジで内側の汚れを落とす。

3. 落ちない汚れには浴槽に適合する中性洗剤を使う。量や置く時間は洗剤の表示に従い、やさしくこする。

4. 洗剤や汚れをよく流し、縁などの水気を拭く。道具をすすいで乾かす。

**注意事項**

- 濡れた浴槽の中や縁に立たない。届かない底は柄付きスポンジを使い、身を乗り出さない。

- 金属たわしや研磨材で強くこすらない。特別なコーティングがある浴槽は専用の手入れ方法を優先する。

- カビ取り剤などを追加で混ぜず、通常洗いで落ちない汚れは材質に合う別の手入れ方法を確認する。

**豆知識・手入れのコツ**

- **浴槽は、汚れが乾き切る前に**：お湯を抜いた後の浴槽は、汚れが乾いてしまう前に洗うと落としやすくなります。特に湯面の高さの線や底の隅は湯あかがたまりやすいので、そこを意識してスポンジを当てましょう。 [花王：浴槽の底面や喫水線が青色に変色したのですが？](https://www.kao.com/jp/qa/detail/26040/)

- 小さな掃除用ブラシ

- 浴室用中性洗剤

### 窓ガラスだけの清掃

**負荷の目安：普通**　実作業の目安：15分

腕を上げ下げしながら、広い面を拭く動きがある。

**必要な道具**

- 柔らかい布

- 乾拭き用の布

- 床に敷く古いタオル

- ガラスに適合する中性洗剤（必要な場合）

**手順**

1. 窓の内側にタオルを敷く。室内の床に立ったまま無理なく届く範囲を作業対象にする。

### 衣類だけの洗濯

**負荷の目安：普通**　実作業の目安：15分

洗濯物の運搬、取り出す前かがみ姿勢、干す動作がある。

**必要な道具**

- 衣類に適合する洗濯用洗剤

- 洗濯ネット（表示に応じて）

- 洗濯かご

- 洗濯機

- ハンガー

- 物干し

- 洗いおけ（手洗いする場合）

**手順**

1. 洗濯表示を見て、家庭で洗える物を色と素材で分ける。ポケットを空にし、ファスナーや飾りを確認して必要な物をネットへ入れる。

2. 機械洗いできる衣類だけを洗濯機の対応容量内に入れ、表示に合うコースと適量の洗剤で洗う。手洗い指定の衣類は別にし、衣類メーカーと洗濯機の案内で機械洗いを認めていなければ、表示どおり手洗いする。

3. 洗い終わったら形を整え、表示に合う方法で間隔を空けて干す。乾燥機を使う場合も衣類と機械の対応を確認する。

4. 完全に乾いたことを確かめ、たたむかハンガーに掛けて収納する。

5. 洗濯機を使った場合は、停止してから使用後清掃が指定された糸くず・乾燥フィルターを説明書どおり手入れする。

**注意事項**

- 防水加工の衣類など、洗濯機で禁止されている物を入れない。衣類側で水洗い可能でも、機械の禁止事項を優先する。

- 洗濯槽へ押し込まず、量が多ければ分ける。運転中の槽に手を入れない。

- 汗や水で濡れた衣類を密閉・山積みにして予定日まで放置しない。早めに洗い、洗い上がりも槽内に放置しない。

- 食用油・美容オイルなどが付いた布類は、洗濯後でも乾燥機で加熱しない。

**豆知識・手入れのコツ**

- **Tシャツのハンガーは裾から**：Tシャツやカットソーをハンガーに掛けるときは、首元ではなく裾から入れ、外すときも裾から抜く。狭い襟ぐりを無理に広げずに済み、首まわりの伸びを防ぎやすい。 [ライオン：洗濯物の干し方のコツ](https://www.lidea.today/articles/002180)

- **靴下は履き口を先に乾かす**：靴下は、基本はゴムの履き口を上にして干すと、傷みやすいゴム部分が濡れている時間を減らせる。つま先が特に厚い物や、洗濯ばさみの跡が気になる物は、つま先を上にするなど製品に合わせる。 [ライオン：洗濯物の干し方のコツ](https://www.lidea.today/articles/002180)

- **ガムは冷やしてから少しずつ取る**：水洗いできる衣類に付いたガムは、氷で冷やすと固くなり、取り除きやすくなる。生地を引っ張らず少しずつ取り、残った汚れは洗濯表示に従って洗う。 [花王 汚れ別のシミ抜き](https://my.kao-kirei.com/kurashi-labo/laundry-cleaning/laundry/012/)

### タオルだけの洗濯

**負荷の目安：普通**　実作業の目安：10分

水を含むと重くなるタオルの運搬と、広げて干す動作がある。

**必要な道具**

- タオルに適合する洗濯用洗剤

- 洗濯かご

- 洗濯機

- 物干し

- 洗濯ばさみ

**手順**

1. タオルの洗濯表示を確認する。色落ちしそうな濃色や、汚れの強い物は別にする。

2. 洗濯機へ詰め込みすぎずに入れ、表示に合うコースと適量の洗剤で洗う。

3. 終了したらすぐに取り出し、一枚ずつ広げて間隔を空けて干す。乾燥機を使うなら表示と容量を確認する。

4. 厚い縁まで乾いていることを確かめてから、たたんで収納する。

5. 機械を停止してから、使用後清掃が指定された糸くず・乾燥フィルターを説明書どおり手入れする。

**注意事項**

- 使用済みの濡れたタオルをかごで重ねたり密閉したりしない。洗うまで広げておき、汚れやにおいが強ければ前倒しする。

- 洗剤や柔軟剤を多く入れても洗浄力は保証されない。製品の使用量を守り、柔軟剤は必要な場合だけ使う。

- 生乾きのまま収納しない。干す場所の換気や間隔を確保する。

- 食用油・美容オイルなどが付いた布類は、洗濯後でも乾燥機で加熱しない。

**豆知識・手入れのコツ**

- **干す前に軽く振るとパイルが起きる**：パイル地のタオルは、干す前に風をあおぐ程度に軽く振って、つぶれた毛足を起こすとふんわり仕上がりやすい。強くバサバサ振るのではなく、軽い動きで行う。 [西川：タオルをふわっと長持ちさせるコツ](https://www.nishikawa1566.com/contents/towel-lifestyle/)

- **収納で押しつぶさない**：乾いたタオルを棚にぎゅうぎゅう詰めたり、何枚も重ねて強く押し込んだりしない。ふんわり感を作るパイルの間の空気を保つには、収納時の圧力を減らすことも役立つ。 [KEYUCA：ふわふわ＆吸水力が続くタオルのお手入れ方法](https://www.keyuca.com/Page/user_data/towel_care.aspx)

参考：[消費者庁：洗濯表示の見方](https://www.caa.go.jp/policies/policy/representation/household_goods/guide/wash_02.html)、[花王：洗たく物が乾きにくい時、ニオイの発生を防ぐには](https://www.kao.com/jp/qa/detail/15871/)、[Panasonic：洗濯機・衣類乾燥機のお手入れ](https://panasonic.jp/wash/contents/care.html)

### シーツの交換・洗濯

**負荷の目安：普通**　実作業の目安：10分

大きな布を広げ、寝具の四隅に手を伸ばして着脱する。

**必要な道具**

- 洗い替えのシーツ（ある場合）

- 洗濯用洗剤

- 大物用洗濯ネット（表示に応じて）

- 洗濯機

- 物干し

- 洗濯ばさみ

**手順**

1. 枕などをよける。シーツの四隅を順に外し、ボックス型のゴムも一か所ずつ解放して取り外す。

3. 表示に合う方法と適量の洗剤で洗う。洗い終えたらすぐ取り出し、重なりを少なくして干す。

### 掛け布団カバーの交換・洗濯

**負荷の目安：普通**　実作業の目安：10分

大きな布団とカバーの向きをそろえ、広げたり抱えたりする。

**必要な道具**

- 洗濯用洗剤

- 大物用洗濯ネット（表示に応じて）

- 洗濯機

- 物干し

- 洗濯ばさみ

**手順**

1. カバーのファスナーを最後まで開き、内側のひもやスナップをすべて外す。布団本体を引きずらないよう抜き出す。

2. 洗濯表示を確認する。カバー内のほこりを取り、ファスナーを閉じて、表示に応じてネットへ入れる。

3. 洗濯機の対応容量内で、表示に合う方法と適量の洗剤で洗う。終わったらすぐ取り出し、内側まで空気が通るよう干す。

4. 完全に乾いたらファスナーを開く。布団とカバーの縦横・四隅を合わせ、内側のひもやスナップを対応する位置へ固定する。

### 食器・調理器具の洗浄

**負荷の目安：普通**　実作業の目安：10分

立った姿勢で複数の食器や器具を持ち替え、力を加減して洗う。

**必要な道具**

- 台所用中性洗剤

- 食器用スポンジ

- 水切りかご

- 清潔な食器拭き用の布

- 食べかすを取る紙

**手順**

1. 食べ残しと多い油を紙などで取り、ごみへ捨てる。熱い鍋は安全に触れられるまで冷まし、包丁は他の食器と分ける。

2. グラスなど油の少ない物から、適量の洗剤を付けたスポンジで洗う。鍋やフライパンは素材に合う柔らかい面を使う。

3. 包丁は一本ずつ、柄を持って刃の位置が見える状態で洗う。刃先に指を向けず、刃を指や布でつまんで滑らせない。

4. 食器と器具を十分すすぎ、水切りかごで乾かす。包丁は刃に触れないよう水気を取り、安全な収納場所へ戻す。

5. 乾いた食器を収納する。残った食べかすを片付け、スポンジと水切りかごを清潔にして乾かす。

**注意事項**

- 包丁や刃のある器具を、泡で中が見えない水や食器の山に入れたままにしない。

- 熱い鍋・フライパンへ冷水を急にかけない。コーティングを金属たわしでこすらない。

- 食洗機を使う場合は食器・器具の対応を確認し、専用洗剤と機種指定の置き方を使う。手洗い用洗剤は入れない。

**豆知識・手入れのコツ**

- **油の付いた皿は、重ねずに運ぶ**：油の多い皿を重ねると、もともと汚れていなかった裏側やほかの食器にも油が広がります。片付けるときから重ねずに分けておくだけで、洗う油汚れを増やさずに済みます。 [花王：一人暮らし充実ガイド・食器洗い](https://my.kao-kirei.com/sp-contents/collaboration/newlife/002/)

参考：[貝印：包丁のお手入れと取扱いFAQ](https://www.kai-group.com/support/faq/cooking/knife/)、[Panasonic：食洗機で洗えないもの](https://jpn.faq.panasonic.com/app/answers/detail/p/1776/a_id/26701)、[花王：食前・食後のそうじの基本](https://my.kao-kirei.com/sp-contents/collaboration/newlife/002/)、[Panasonic：食洗機で一般台所用洗剤を使ってはいけない理由](https://jpn.faq.panasonic.com/app/answers/detail/a_id/84383/p/4036/related/1)

### 調理台・コンロの軽い清掃

**負荷の目安：軽い**　実作業の目安：5分

**必要な道具**

- 乾拭き用の布

- 素材に適合する台所用中性洗剤

- 食品くずを取る紙

- ゴム手袋

### 厚手カーテンの洗濯

**負荷の目安：重い**　実作業の目安：20分

大きく重い生地の着脱・運搬と、腕を上げて支える作業がある。

**必要な道具**

- 衣料用中性洗剤

- 大きな洗濯ネット

- 洗濯かご

- 洗濯機

- 生地の重さを支えられる物干し

- フックを入れる容器

- 生地が収まる洗いおけ（手洗い指定の場合）

**手順**

1. 洗濯表示で家庭洗濯の可否と乾燥方法を確認する。洗濯機の対応容量と干す場所を確かめ、窓際の足元を片付ける。

2. 生地を支えながらレールから一枚ずつ外す。床上の作業しやすい場所で、フックをすべて外して容器へ入れる。

3. ほこりを取り、ひだに沿ってたたんでネットへ入れる。洗濯表示と機械の説明書に合うコース・洗剤量で洗う。手洗い指定なら、洗える大きさの容器で押し洗いし、十分すすぐ。

4. 表示に合う脱水を行い、すぐ取り出して形を整える。レールに戻して干せる製品で、レールの耐荷重にも問題がない場合は、フックを戻してから掛ける。それ以外は生地の重さを支えられる物干しで干す。

5. 十分に乾いたことを確かめ、物干しで乾かした場合はフックを戻して掛け直す。すべてのフックが掛かり、生地が床に引きずられないか確認する。

**注意事項**

- 椅子やぐらつく台に上らない。安全な足場でも体を伸ばさないと届かない、または生地を支えられない場合は、手伝いや専門サービスを頼む。

- 水を含むとさらに重くなる。洗濯機に押し込まず、一人で持ち上げにくければ家庭での作業を止める。

- 洗濯不可・表示不明の生地や付属品を自己判断で水洗いしない。乾燥機も使用可否を確認する。

### レースカーテンの洗濯

**負荷の目安：普通**　実作業の目安：15分

### 靴箱内部の清掃

**負荷の目安：普通**　実作業の目安：15分

**必要な道具**

初期表示は「部屋」「浴室」「トイレ」などの単位とし、部位ごとの説明があるだけで家事を増やさない。

## 明示された分割項目を使う

| 家事 | 初期のまとめ方 | 今回使用する分割項目 |
| - | - | - |
| 部屋の清掃 | 家具・棚のほこり取り、床のごみ取り、必要な拭き掃除 | 床だけの清掃と家具・棚のほこり取り。未定義の部屋別分割は追加しない |
| 浴室の清掃 | 床・壁、排水口のごみ受け、鏡・蛇口、使用する浴槽の通常清掃 | 浴槽だけ、排水口、浴槽・排水口以外の3項目。使用後工程を日数周期へ変換しない |
| トイレの清掃 | 便器・便座・床・周囲の拭き取り | 専用分割候補は設けず、任意の部分分割は追加しない |
| 洗面台の清掃 | ボウル・蛇口・鏡・ごみ受け | 初期の専用分割候補は設けない |
| シンクの清掃 | シンク本体・排水口まわり・ごみかご | 排水口・ごみかごと、排水口以外のシンク本体 |
| 窓まわりの清掃 | 網戸・ガラス・サッシの通常清掃 | 網戸、ガラス、サッシ。作業対象を重複させず選ぶ |
| 衣類・タオルの洗濯 | 洗う・乾燥する・取り込む・収納する一連の作業。該当する糸くず・乾燥フィルターの使用後清掃を含む | 衣類だけの洗濯とタオルだけの洗濯。干す・取り込む等の工程を別周期の定期家事にはしない |
| 寝具カバーの交換・洗濯 | 使用しているカバー類の交換と洗濯 | 枕カバー、シーツ、掛け布団カバー。任意の組み合わせで残る一式の値は推測しない |
| 調理後の片付け | 食器・器具、調理台・コンロの軽い拭き取り、使用機器の使用後手入れ | 食器洗いと調理台・コンロ清掃。使った機器の手入れはその回の対象に限る |
| カーテンの洗濯 | 一緒に洗うカーテンを一つの対象として登録 | 厚手カーテンとレースカーテン。未定義の部屋別分割は追加しない |
| 玄関の清掃 | 玄関床を基本に、必要時に靴箱内の清掃を追加 | 靴箱内部を別頻度で扱いたい場合に分離 |

カビ取りと頑固な水あか落としは、通常清掃の説明に「見つかった場合の追加手順」として統合する。毎回必須・別通知にはしない。追加時間は作業の目安であり、アプリが実施の有無を推測して予定時間へ自動加算する指定ではない。排水トラップ内部の手入れと網戸の取り外し洗浄は、通常清掃より対象・方法が広いため、任意の別管理候補を残す。薬剤や材質の安全条件は、まとめ方にかかわらず守る。

## 初めから別の予定単位にする

| 対象 | 分ける単位 | 理由と扱い |
| - | - | - |
| 冷蔵庫 | 庫内清掃と自動製氷機のお手入れ | 対象・完了条件が違う。製氷機は搭載かつ使用する場合だけ |
| 洗濯機 | 槽のお手入れと排水フィルター。糸くず・乾燥フィルターは洗濯手順へ統合 | 機種に存在し使用する部品だけ。週次の排水フィルターは、その週の洗濯と同時に行えるが、洗濯完了だけで清掃済みにはしない |
| 寝具 | カバーの洗濯、寝具の乾燥・吸引、寝具本体の洗濯 | 方法・対象・負担が異なる。乾燥・吸引も一緒に行わない場合は分離可能 |
| マット・ラグ | 実際に使うバスマット、キッチンマット、ラグ等の対象別 | 一つの周期で全種類を洗う設定にしない。同日に洗っても別管理のままとし、実施内容を推測して統合しない |
| 換気設備 | 居室等の換気口と浴室換気設備 | 別の設備として管理。同種の換気口の数に応じた変更は本人の明示設定を使い、実施した箇所数を推測しない |
| コンロ | 調理後の軽い拭き取りと念入りな清掃 | 通常の片付けで、分解可能な部品等の念入りな清掃を完了にしない |
| ごみ | ごみ箱の汚れ対応をごみ出し・袋交換の説明へ統合 | 汚れ・液漏れ・においがあれば清掃。定期清掃を別管理したい人だけ独立登録し、ごみ出しだけでその完了履歴を更新しない |
| 窓とカーテン | 窓まわりの清掃とカーテンの洗濯 | 同日に行っても完了対象は別 |
| 掃除機と部屋 | 部屋の清掃と掃除機のお手入れ | 掃除機で床を掃除しても、機器のフィルター等は清掃したことにならない |

その他の機器は機器別の登録を維持する。タンク・フィルター等の周期が違う場合は対象部品別に分けるが、機種情報を確認せずに全利用者へ同じ分割を強制しない。複合機の加湿空気清浄機などは、二つの機器として重複登録しない。

## 分割と同日の実施の扱い

「別管理」と「同じ日にまとめて行う」は両立できる。別管理している家事は個別の周期・完了履歴を保ち、通常の完了操作で実施した家事だけを記録する。同時実施を確認する追加入力や一括入力の新機能は作らない。

分割後の作業範囲・目安値が明記された項目だけを使う。浴室では浴槽、排水口、浴槽・排水口以外を区別し、ある項目の完了で未実施の別項目を完了にしない。親子の重複登録を避け、親から一部だけを引いた未定義の残作業値は作らない。

調理後にシンクの生ごみを片付けただけでは「シンクの清掃」を完了にしない。シンク・排水口・ごみかごの設定された範囲まで清掃した場合に限り、その家事の完了として記録できる。

# 初期状態で有効にする家事

初めて一人暮らしをする人向けの開始セットは、基本8件とする。初期設定で本人が担当しない家事や該当しない設備を外せるようにする。以下の「有効」は管理対象として選択する意味であり、全件を初日に実施・期限超過として並べる意味ではない。

## 基本の8件

1. 部屋の清掃

2. 浴室の清掃

3. トイレの清掃

4. 洗面台の清掃

5. シンクの清掃

6. 玄関の清掃

7. 衣類・タオルの洗濯

8. 寝具カバーの交換・洗濯

居室・水回り・衣類・寝具の基本的な手入れを対象にする。ごみ箱の汚れ・液漏れ・においへの対処は、ごみ出しや袋交換の説明に含め、初期の独立家事から外す。ごみ箱を定期的に洗いたい人は任意で追加できる。8件はLiFlowの開始セットとしての選択。

共用浴室・トイレを管理者が清掃する住まいなどは対象を外す。洗面ボウルが浴室内にあり一緒に洗う場合は、洗面台清掃を浴室に含めて別登録を外せる。名称が違うだけで同じ対象を二重に管理しない。

## 設定が済んだら有効にするごみ出し

ごみ出しは基本導線に含めるが、地域の収集日と分別区分を設定してから予定を出す。未設定中は「収集日の設定待ち」とし、仮の曜日で通知しない。既存のゴミ収集日機能を利用し、同じごみ出しを通常家事として二重登録しない。

## 所持と使用を確認して有効にするもの

| 条件 | 有効化する候補 |
| - | - |
| 冷蔵庫・電子レンジを使用する | 冷蔵庫内の清掃、電子レンジ庫内の清掃 |
| 自動製氷機を使用する | 自動製氷機のお手入れ |
| 自宅の洗濯機を管理する | 洗濯槽のお手入れ、該当する排水フィルター清掃。糸くず・乾燥フィルターは洗濯の説明に含める |
| 自分が清掃するコンロ・レンジフードがある | コンロ周りの念入りな清掃、レンジフードのお手入れ |
| エアコン・換気設備を自分で手入れする | エアコンフィルター、換気口、浴室換気設備の各手入れ |
| 対象機器を使用する | 食洗機、加湿器、空気清浄機、掃除機・ロボット掃除機、電気ケトル・ポット、トースター、扇風機・サーキュレーター、除湿機の各手入れ |
| 自分で安全に清掃できる窓・ベランダがある | 窓まわりの清掃、ベランダの清掃 |
| 対象の布製品・寝具を使用する | カーテン、マット・ラグ、寝具の乾燥・吸引、寝具本体の洗濯。洗えないものには洗濯を登録しない |

初期設定で「持っている・使っている・自分が手入れする」を確認した対象だけを選択済みにする。未回答は未確認のままとし、所有を推測して有効にしない。確認後も利用者が外せるようにする。低頻度という理由だけでカーテンや窓の清掃を除外せず、実施頻度は周期の設定側で調整する。

## 初期は無効として任意で追加するもの

- 調理後の片付けと、その分割項目である食器洗い。自炊の有無だけで毎回の記録を必須にせず、アプリで管理したい人が選ぶ。

- 排水トラップ・排水管の手入れ、網戸の取り外し清掃などの追加作業。カビ取り・水あか落とし・ごみ箱の清掃は親の家事の説明に統合し、独立管理は希望者だけにする。

- 靴のお手入れ、季節衣類のしまい洗い・収納、アイロンがけ。

- 住宅用火災警報器の作動確認、電源プラグ・電源タップの清掃と状態確認。安全点検は初期無効とし、ここに説明があることを理由に独自の追加通知や記録入力を作らない。

- 追いだき配管の洗浄は、設備条件と方法の確認が済むまで収録判断自体を保留する。

買い足し・食品整理・包括的な換気習慣・調理予定などの保留項目は、初期セットに追加しない。初期有効化に伴って架空の完了履歴を作らず、全件を即日の期限超過にしない。
